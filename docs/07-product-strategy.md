## 1. 愿景与产品原则

### 1.1 愿景陈述（一句）

> **让每一个刚起步的垂类创作者，第一条视频就有人看——并且知道自己为什么被看见。**

**为什么是这一句（而不是别的）**

| 被否决的愿景表述 | 否决理由 | 依据 |
|---|---|---|
| 「成为最大的短视频平台」 | 与「用户 10.74 亿、使用率 95.4%、年增速 0.8%」的存量事实直接冲突；通用赛道不可进入 | `[F0-§2.1][F0-§2.2]` |
| 「用 AI 重新定义内容分发」 | 无行为数据阶段上 DNN 是负收益；且五家头部推荐链路已同构，功能清单不构成差异 | `[F0-§2.3][F3-提示2]` |
| 「更聪明的信息流」 | 抖音的「去标签化神经预估」需要亿级数据与算力，无法在早期比拼 | `[F3-§3.1][F3-结论1]` |
| **选定表述** | 锚定 PRO-4 归因出的**唯一机会窗口（发布 → 反馈环节）**与**最高风险假设 A1**；同时把「可解释」写进愿景，防止承诺变成不可核对的营销话术 | `[F4-§2.3 判读2][F4-A1]` |

### 1.2 产品原则（5 条）

每条原则都给出「可验收的产品含义」与「违背它的典型反例」，避免原则退化为口号。

| # | 原则 | 含义 | 可验收的产品含义 | 依据 | 违背它的反例 |
|---|---|---|---|---|---|
| **P1** | **供给先于消费** | 冷启动期平台无消费价值，唯一增长引擎是供给；按垂类而非总量做供给 | 上线节奏以「垂类内容密度」为开关：`tag` 召回路有邻居可召之前不投消费侧流量 | `[F0-§2.2 B][F4-§2.3 判读2][GTM-§四]` | 用投放买 DAU，把用户带进空房间 |
| **P2** | **确定性 > 爆发力** | 不承诺「爆」，承诺「不白干」 | 首发 24h 曝光 **P10 ≥ 50 且同批创作者曝光基尼系数 ≤ 0.6**（A1 判据）；新视频不进淘汰池 | `[F4-A1][GTM-§2.1]` | 用「爆款率」做宣传，掩盖多数人零曝光 |
| **P3** | **公平必须可度量** | 公平不能是运营态度，必须是算法层约束 | 单创作者在单条 feed 内 ≤ 2 条；创作者曝光 Gini > 0.6 触发流量再平衡；> 0.7 强制提升探索流量 | `[F4-A1 判据][F3-§3.3 快手基尼系数约束（E3，方法先例）][GTM-§六 反指标]` | 只喊「扶持中长尾」而无量化约束 |
| **P4** | **每一步都要可解释** | 推荐与上传失败都要能归因，规则对创作者公开 | `/api/feed` 每条返回 `features` + `reason`；上传失败返回 8 类具名错误码；分成规则先公开后结算 | `[F4-§2.2 创作者 P0「上传失败可理解」][F4-A6/G7][F3-结论4（YouTube Shorts 45% 为唯一官方透明标杆，E4）]` | 黑箱流量 + 静默失败，创作者只能猜 |
| **P5** | **规则与标签先于模型** | 无数据阶段不做过拟合的工程；先要可解释基线 | 排序采用线性加权 + 标签/协同召回，不上 DNN；权重全部走配置而非硬编码 | `[F0-§五 排序模型 trade-off][F4-A8][F3-结论1]` | 在无数据阶段投入双塔训练，得到无法归因的黑箱 |

### 1.3 战略切口裁定：取 A × B 的交集，否决 C

| 切口 | 立项评估给出的依据与代价 | 本单裁定 | 理由 |
|---|---|---|---|
| **A. 垂直品类深耕** | 通用平台长尾垂类创作者拿不到确定性流量；50–59 岁「新银发」占 20.9%（行业唯一增量）；代价：天花板低 | ✅ **采纳（作横向轴）** | 低天花板可通过「相邻垂类共享画像」延展（美食→探店→本地生活）`[GTM-§八]`，但这是唯一能在早期建立内容密度的路径 |
| **B. 创作者侧确定性供给** | 用户旅程情绪断崖集中在「首次发布 → 首次收到反馈」；存量竞争胜负手在供给侧；代价：需补贴或机制设计 | ✅ **采纳（作纵向轴，且是本产品的核心差异）** | 关键洞察：确定性可用**自然流量分配机制**兑现（fallback 路由 + 新视频保护期），边际成本≈0，不必走付费补贴 `[GTM-§八 风险1 对冲]`；而纯补贴已被证伪 `[F3-结论4]` |
| **C. 私域/关系链冷启动** | 视频号证明分发路径本身可差异化；代价：依赖既有关系链资产 | ❌ **否决** | **从零起盘不可复制**——本产品没有任何关系链资产；若强行模仿视频号，会得到「既无算法效率、又无社交密度」的最差组合 `[F0-§2.2 C]` |
| （基线）通用短视频赛道 | 用户渗透率 95.4%、增速 0.8%、头部集中度极高 | ❌ **否决** | 「做一个更好的抖音」在本项目资源条件下不可成立 `[F0-§2.1]` |

**裁定结论：本 MVP 的战略切口 = 「垂类深耕 × 创作者侧确定性供给」的交集。** 该交集使两个决策互相强化：垂类让「内容密度」可在小规模达成，确定性供给让垂类创作者愿意把首发留在本平台。

## 2. 目标细分市场与定位

### 2.1 三类细分中的选择

| 细分 | 在平台内的经济角色（PRO-4 原判） | 本单定位裁定 | 依据 |
|---|---|---|---|
| **B. 兴趣内容创作者**（副业动机、业余时间创作、中等频次供给） | 内容供给与商业化潜力 | ✅ **楔子人群（beachhead）：其中「已做垂类内容、在通用平台拿不到确定性流量」的子集** | `[F4-§1.2]` |
| **A. 泛娱乐观众**（含 50–59 岁银发子群） | 时长与活跃度基本盘（留存目标） | ✅ **留存目标人群：其中「对该楔子垂类有兴趣」的子集** | `[F4-§1.1]` |
| **C. 垂类 / 本地创作者** | MVP 无 LBS / 电商能力，**不作为留存目标** | ⚠️ **仅作内容供给与标杆来源；其变现类需求（挂载、佣金、到店核销）转本单 §4 与后续迭代** | `[F4-§1.3]` |

**聚焦到「垂类子集」而非全量细分，是刻意的收紧：** 1,000 个美食创作者的价值远高于 1,000 个跨品类创作者——因为内容密度不足时 `tag` 召回无邻居可召，飞轮在第 ③→④ 步断裂 `[GTM-§四]`。

### 2.2 为什么是这群用户（3 条理由，均可追溯）

1. **他们的痛点最集中、且已被证明是最高的项目风险。** PRO-4 把「新创作者首发曝光确定性」评为**影响度高 × 证据强度 E2** 的最高风险区（Top 3 第 1 位）；「冷启动流量不确定、爆不爆像玄学」是其用户语言 `[F4-§3.1 A1][F4-§1.2]`。
2. **存量竞争下胜负手在供给侧，而非需求侧。** 日均上传 > 1.3 亿条（E2/E3 转述）意味着「发得出去不是问题，被看见才是问题」；需求侧已在 95.4% 渗透率下饱和，可争夺的只有「创作者把内容放在哪里」`[F0-§2.2 B][F4-§1.2]`。
3. **他们的诉求与观众留存的诉求是同一件事的两面。** 观众侧唯一的留存引擎是首刷命中（A2），而命中率依赖垂类内容密度；供给确定性 → 密度 → 命中 → 留存 → 创作者获得真实反馈，这是同一个闭环 `[F4-§1.1][F4-A2][GTM-§四]`。

**为什么不选另外两类作楔子（显式记录）：**
- 不选细分 A 作楔子：观众侧是「存量中的存量」，无供给时无法独立冷启动；且验证 A2 需要先有内容池 `[F4-§4.4]`。
- 不选细分 C 作楔子：MVP 无 LBS、无电商、无支付（Non-Goal），C 的核心 JTBD（本地精准曝光 + 到店闭环）**在本 MVP 内无法被满足**；把 C 当留存目标会造成「承诺了做不到的功能」`[F4-§1.3][F0-§2.3]`。C 的迁移意愿（A7，影响度高、**证据强度 E1 无证据**）由本单 §5 承接为风险项，由 PRO-8 承接为种子计划。

### 2.3 差异化定位声明（Positioning Statement）

> **对于** 在通用平台长期拿不到确定性流量、把内容当副业或事业经营的**垂类创作者**（美食 / 宠物 / 健身 / 读书 / 手作等），
> **他们受够了** 发 20 条只有 3 条被看见、却始终无法知道原因，
> **本产品是** 一个把「首发曝光确定性」做成**工程机制**而非运营承诺的**垂类短视频社区**，
> **不同于** 抖音 / 快手的效率赛马与视频号的社交分发，
> **我们以可度量的分发公平与全链路可解释性作为产品约束**：同批创作者曝光基尼系数 ≤ 0.6、单创作者在单条 feed 内 ≤ 2 条、每条推荐附带可核对的理由。

**压缩版（对外一句话，供 GTM 使用）**：我们不承诺「爆」，我们承诺「不白干」——并且把这句话变成可核对的数字。

**与现有 GTM 定位的关系：** `[GTM-§2.1]` 已给出方向一致的定位声明（"保证首发光有曝光、并用数据告诉你为什么"）。本单做两处收紧：①把「刚起步的垂类创作者」明确为细分 B 的垂类子集，并显式排除细分 C 作为留存目标；②把「保证」替换为**可度量约束**（Gini / 每 feed 条数上限 / reason 字段），使承诺可核对、可回滚。

**定位的三条边界（不是什么都做）：**
1. 不做全品类 —— 与通用平台的正面竞争被 `[F0-§2.1]` 否决；
2. 不做创作工具 —— PRO-4 判读 3 已明确「MVP 不可能靠创作体验赢，只能靠发布成功率 + 曝光确定性赢」`[F4-§2.3]`；
3. 不做社交分发 —— 无关系链资产 `[F0-§2.2 C]`。

### 2.4 定位的可证伪条件（必须与实验绑定）

| 触发条件 | 定位后果 | 依据 |
|---|---|---|
| 假门测试中 V1（确定性）− max(V2 收益透明, V3 省时间) **< 3pp** | 「确定性」不是主驱动因素 → 定位叙事改为「收益/规则透明」 | `[F4-§4.3]` |
| **A1 被证伪**（首发 24h 曝光 P10 < 50 或 Gini > 0.6） | 定位前提失去支撑 → 转向消费侧体验叙事；本策略第 1–3 章需整体改写 | `[F4-§3.1 A1]` |
| **A7 被证伪**（< 50% 垂类创作者愿首发或 30 日留任 < 50%） | 战略改写为「多平台分发工具」，核心痛点从「被看见」改为「省时间」 | `[F4-§3.1 A7]` |

## 3. 价值主张与 3 条关键差异点

### 3.1 价值主张

> **给垂类创作者：一个可核对的曝光下限 + 一份可读懂的原因。**
> 给观众：一个不重复、不踩雷、能持续追某个兴趣的流。

价值主张的成立前提是 A1（创作者侧）与 A2（观众侧）同时成立；两者都是 PRO-4 定义的 Top 3 假设，**因此本策略不是「已成立的事实」，而是「用 MVP 去验证的一组赌注」** —— 这是本单必须诚实标注的最重要限定 `[F4-§5.1]`。

### 3.2 三条关键差异点（每条均锚定上游事实）

| # | 差异点 | 锚定的上游事实 | MVP 承载 | 度量方式 | 若不成立 |
|---|---|---|---|---|---|
| **D1** | **首发曝光确定性是机制，不是承诺** | 「首次发布 → 首次收到反馈」是创作者旅程的情绪断崖中心；新号初始曝光确定性被标为 Top 3 假设 A1（E2 / 影响度高）；需求地图创作者侧 P1「新号初始曝光的确定性」现状为「机制存在但确定性未验证」`[F4-§1.2][F4-§3.1 A1][F4-§2.2]` | `fallback` 兜底路由 + `tag`/`fresh` 召回承接新视频（无互动、无标签时仍可获得初始曝光）；新视频保护期不进淘汰池；`video_stats` 反规范化计数器使曝光可实时统计 `[PRD-§3.3]` | 首发 24h 曝光 **P10 ≥ 50**；同批创作者曝光 **Gini ≤ 0.6** | 定位前提崩塌 → 见 §2.4 分支 |
| **D2** | **分发公平可度量（可回滚）** | 快手以**基尼系数作为强约束指标**、约 80% 流量向中长尾倾斜，证明「曝光分布公平性可被量化」有方法先例（E3，券商研报）；PRO-4 直接把 Gini ≤ 0.6 写入 A1 判据；需求地图 P0「不连续同类」痛点为「刷十条都一个样」`[F3-§3.3][F4-A1][F4-§2.1]` | MMR 多样性重排（λ=0.7）+ 单创作者单 feed ≤ 2 条 + 7 天已看过滤 + ε-greedy 10% 探索位 `[PRD-§3.2]` | 会话内同类连续 ≤ 3 条；Gini ≤ 0.6（> 0.7 强制提升探索流量）；护栏：人均观看时长 ≥ 对照 × 0.95 | 只是参数回退（λ 上调 0.85 或改类目软打散），**不构成方向失败** —— 故列为护栏假设而非 Top 3 `[F4-§3.2 A3]` |
| **D3** | **全链路可解释：推荐理由 + 失败原因 + 规则公开** | 观众侧 P1「可解释（为什么推这条）」与创作者侧 P0「上传成功率高、失败可理解」；创作者侧 P2「分成透明 / 结算清晰」现状为「规则是个黑箱」（E2）；YouTube Shorts 是唯一公开固定 45% 分成的平台（官方一手，E4/A 级）`[F4-§2.1][F4-§2.2][F3-§4.2]` | `/api/feed` 每条返回 `features` + `reason` + `recall_routes`；上传失败统一错误信封（8 类具名错误码）+ sha256 去重 409 明确告知原 id；分成规则**先公开后结算** `[PRD-§3.1][PRD-§3.2]` | 推荐可归因覆盖率 100%（每条 feed 均带 `reason`）；错误码覆盖率 100%（无静默失败）；规则页上线即视为承诺生效 | 该差异点是**低成本高可信度**项（不依赖算法能力），失败概率低；若 A6 证伪（显式调控使用率 < 5%）则砍掉调控 UI，仅保留埋点与内容化说明 `[F4-A6]` |

### 3.3 不成立的「差异点」（避免自欺，必须显式排除）

| 常被当作差异点的能力 | 为何在本项目不成立 | 依据 |
|---|---|---|
| 推荐算法更准 / 更懂用户 | 五家头部的推荐链路已**同构**（多路召回 → 多目标排序 → 重排打散）；差异化只能来自目标权重与分发哲学，而非功能清单 | `[F3-提示2][F3-§3.1]` |
| 内容池更大 / 品类更全 | 与 10 亿级 MAU 平台的存量规模不可能在资源可比的前提下竞争 | `[F0-§2.1]` |

| 秒开 / 不卡顿 / 弱网可播 | 属 **P0 卫生条件**（缺失即流失），不是差异点；做到不构成优势，做不到则一切归零 | `[F4-§2.1 P0]` |

| 补贴 / 高额创作激励 | 纯补贴模式已被证伪（买来的创作者没有留存动力） | `[F3-结论4]` |

## 4. 商业模式

### 4.1 MVP 阶段取舍（结论先行）

> **MVP 阶段：零变现（no monetization surface）。唯一与变现相关的动作是「把规则公开，但不结算」。**

三条理由：

1. **广告需要可售库存，MVP 没有。** 广告是头部平台的第一引擎（抖音广告约 4200 亿元、占国内营收 46.6%；小红书广告占营收 76%，均为财报类 E3），但那是在十亿级 MAU 与百亿级日播放之上的结论；在本 MVP 的 DAU 量级下 eCPM 与填充率都无意义 `[F3-§4.1]`。
2. **打赏与订阅在本阶段会分散资源且与定位冲突。** 打赏依赖头部效应；订阅要求用户量级与独占内容供给；GTM 已明确「阶段 3 才做，且不打赏/不做会员订阅」`[GTM-§三 阶段3]`。
3. **电商/LBS 依赖 MVP 明确排除的能力。** 电商、打赏、支付均为 Non-Goal；细分 C 的到店闭环需求在本 MVP 内不被承接 `[F0-§2.3][PRD-§1.3][F4-§1.3]`。

### 4.2 四条变现路径评估与启动门槛

门槛值中标注 **〔E1/待校准〕** 者为团队设定的开关条件，**不是行业基准**，须在灰度后用真实分布校准（继承 PRO-4 的阈值纪律）。

| 路径 | 与本定位的适配度 | MVP 取舍 | 启动门槛（可计算） | 依据 |
|---|---|---|---|---|
| **广告**（信息流 + 评论区广告） | **高** | ❌ 不做，但**口径先行**（先定义播放量/曝光口径，避免后续无法结算） | DAU ≥ 100,000 **且** 日均有效播放 ≥ 500 万次 **且** 内容池 ≥ 30,000 条 〔E1/待校准〕 | 抖音/小红书广告为主要营收 `[F3-§4.1]`；视频号「评论区广告分成」是低成本、低门槛路径 `[F3-§4.2]` |
| **垂类商单撮合**（本地商家 × 垂类创作者，平台抽佣） | **中高**（垂直平台的天然优势，通用平台做不深） | ❌ 不做，**MVP 后的第一优先级变现** | 垂类内容密度达 §4.2 广告门槛的 1/3 **且** 有 ≥ 50 名可接单创作者 〔E1/待校准〕 | `[GTM-§三 阶段3]` |
| **打赏** | **低** | ❌ 不做 | 创作者次周留存 ≥ 40%（即创作者已形成稳定回访习惯）〔E1/待校准〕 | 依赖头部效应；GTM 明确不做 `[GTM-§三]` |
| **订阅 / 会员** | **低** | ❌ 不做 | DAU ≥ 500,000 **且** 存在独占内容供给 〔E1/待校准〕 | 早期用户量不足 `[GTM-§三]` |
| **电商闭环** | **中**（垂类天然适配） | ❌ 不做（Non-Goal：无支付、无 LBS） | 需先补齐支付与 LBS 能力，且创作者侧 G1–G5 缺口全部关闭 | `[F0-§2.3][PRD-§1.3]` |

**口径先行的具体含义（对 PRD/工程的唯一要求）**：`view` / `exposure` / `完播` / `有效播放` 四个口径必须在埋点落地时一次性定义并冻结，跨平台比较前须先对齐（PRO-3 已明确：Shorts/Reels 为「开始播放即计」，抖音/快手以播放量为分母，**跨平台不可直接比**）。本单要求在 PRD 中固化本表 §4.4 的口径定义。

### 4.3 成本结构与单位经济：本定位能成立的关键前提

| 项 | 设计 | 为什么这是战略级的 |
|---|---|---|
| **曝光保底的兑现成本** | 用**自然流量分配机制**兑现（`fallback` 路由 + `tag`/`fresh` 召回 + 新视频保护期），而非付费流量采买 | 边际成本 ≈ 0。若确定性必须靠现金补贴兑现，本定位会变成不可持续的烧钱叙事；GTM 已把「保底曝光成本失控」列为高影响风险并把此机制作为对冲 `[GTM-§八]` |
| **创作者回报模型（承诺口径）** | 广告收益**固定比例分成**（参照 YouTube Shorts 公开的 45%，是本行业中唯一官方一手、可核对的透明标杆，E4/A 级） | 固定比例比「黑盒补贴」更能建立创作者信任；同时避免「平台自留比例不透明」这一创作者侧 P2 痛点 `[F3-§4.2][F4-§2.2]` |
| **成本侧红线** | 不用补贴换供给；不用投放换 DAU（供给侧密度达标前不投消费侧） | 直接对应「纯补贴被证伪」与「过早投放 = 把用户带进空房间」`[F3-结论4][GTM-§三 阶段2]` |

### 4.4 北极星指标与一级指标（含可计算的分子/分母）

#### 4.4.1 北极星指标（沿用 `[F0-§2.3][GTM-§六]` 的口径，本单补齐计算定义）

> **北极星 NS = 创作者次周留存率（W2_CRR） × 人均有效观看时长（EVT）**

| 组成 | 分子（Numerator） | 分母（Denominator） | 频次 | 目标（阶段 2 末） |
|---|---|---|---|---|
| **W2_CRR** 创作者次周留存率 | 在**第 W 周**有效发布的创作者集合中，**第 W+1 周仍有效发布**的创作者去重人数<br>（有效发布 = `POST /api/videos` 返回 201，**且**该视频 24h 内曝光 ≥ 1） | 第 W 周**有效发布**的创作者去重人数（`POST /api/videos` 返回 201 的 distinct `creator_id`） | 周 | ≥ **0.40** |
| **EVT** 人均有效观看时长 | Σ 当日**有效观看**事件的 `watch_ms`，其中**有效观看 = 单次 `watch_ms` ≥ 3000ms 且已上报 `kind=view`**（口径冻结，见 §4.2） | 当日去重活跃用户数（DAU：当日有 ≥ 1 条 `kind=view` 的 distinct `user_id`） | 日（取 7 日滚动中位数上报） | ≥ **25 分钟/人·日** |
| **NS** | W2_CRR × EVT | —— | 周 | ≥ **10.0**（= 0.40 × 25） |

**使用纪律（必须遵守，否则指标会被误用）**
1. 两个因子**量纲不同**（周粒度比率 × 日粒度时长），因此 NS 只用于**同周环比与实验组间比较**，不得做跨周绝对值排名。
2. **任一因子为 0 则 NS 为 0** —— 这正是选乘积而非单指标的原因：单看 DAU 会掩盖「只有消费没有供给」的空心化；单看创作数会掩盖「发了没人看」的挫败。任何一侧掉链子都会立刻显形 `[GTM-§六]`。
3. NS **不是**对外宣传口径；对外使用 §2.3 的压缩版承诺与 §4.4.2 的护栏数字。

#### 4.4.2 一级指标（L1）与护栏指标

| 层级 | 指标 | 计算口径（分子 / 分母） | 目标（阶段 2 末） | 依据 |
|---|---|---|---|---|
| 供给 | 周活跃创作者数（WAC） | 周内成功发布 ≥ 1 条视频的 distinct `creator_id` | ≥ 5,000 | `[GTM-§六]` |
| 供给 | **首发 24h 曝光 P10** | 新创作者首条视频发布后 24h 曝光量分布的**第 10 百分位** | **≥ 50** | `[F4-A1]` |

| 供给 | 免引导首次上传完成率 | 无引导条件下发布成功人数 / 受测人数 | ≥ 80%；中位耗时 ≤ 90s；求助率 ≤ 5% | `[F4-A4]` |
| 消费 | DAU | 当日有 ≥ 1 条 `kind=view` 的 distinct `user_id` | ≥ 100,000 | `[GTM-§六]` |
| 消费 | 次日留存 D1 | 次日回访用户数（第 D+1 日有 view）/ 第 D 日新增用户数 | ≥ 25% | `[GTM-§六]` |

| 消费 | 20 秒退出率 | 进入 feed 后 20s 内离开的会话数 / 进入 feed 的会话数 | **< 40%** | `[F4-A2]` |
| 消费 | 完播率 | 完整播放量 / 播放量（口径见 §4.2） | ≥ 45% | `[GTM-§六]` |
| 生态（护栏） | 举报率 | 举报数 / 曝光数 | ≤ 0.5%（> 1% 回滚最近一次排序权重变更） | `[F4-§5.2][GTM-§六]` |
| 生态（护栏） | 跳过率 | skip 数 / 曝光数 | ≤ 40%（> 50% 检查内容与画像错配） | `[F4-§5.2][GTM-§六]` |
| 生态（护栏） | 单创作者单 feed 条数 | 单条 feed 内同一 `creator_id` 的最大条数 | ≤ 2 | `[PRD-§3.2][F4-§5.2]` |
| 生态（护栏） | 7 天重复推荐率 | 7 天内已互动视频再次出现的条数 / feed 总条数 | = 0 | `[PRD-§3.2]` |

**护栏条款的强制写法（供 PRD 直接引用）**：上述供给与消费指标的达标**不得以恶化为代价** —— 举报率 < 0.5%、单创作者在单条 feed 内 ≤ 2 条、7 天内已看不重复推荐、人均观看时长不下降。`[F4-§5.2]`

| 测量基础设施 | 最小鉴权 + 限流 + 首刷标记/退出事件埋点 + 注册期可选兴趣标签（3 选，用于 A2 的 ground truth） | P0（前置） | 不补齐则 A2/A3/A8 结论不可信；属「任何效果实验前必须完成」的门槛 `[F4-§4.7][F4-§6 G2/G3/G6]` |

### 6.2 Out of scope（MVP 明确不做，含复查触发条件）

| 不做项 | 说明 | 复查触发条件 |
|---|---|---|
| 视频编辑（剪辑/滤镜/模板/音乐库） | 创作阶段需求整体后置 | 发布侧 P0 达标且上传失败率已量化 |
| 断点续传 / 上传进度条 | 需求优先级 P1；但**必须先把失败率量化**（否则无法判断是否需要） | 上传失败率的量化结果 > 5% |
| 关注页 / 消息 / 推送通知 | 社交关系沉淀属 P1/P2 | 阶段 2 消费侧指标达标 |
| 搜索 / 话题聚合页 | 观众侧 P1，未实现 | 垂类内容密度达标（每垂类 ≥ 500 条） |
| 创作者数据看板（完整版） | 仅保留 §6.1 的最小曝光反馈位 | A5 验证通过 |
| 多平台一键分发 | 假门 V3「省时间」变体若胜出则重新评估 | 若 V3 成为主驱动（V3 − max(V1,V2) ≥ 3pp）则**立即重估** |
| LBS / 电商 / 支付 / 打赏 / 订阅 | 战略级 Non-Goal | 见 §4.2 启动门槛 |
| 移动端原生 App | 先 Web + 移动 Web | 阶段 2 消费指标达标 |
| DNN 排序 / 实时特征 | 见 NG5 | A8 验证通过 |
| 完整分成结算系统 | MVP 仅公开规则、不结算 | 广告门槛达成 |

### 6.3 PRD 可直接粘贴的验收条款

1. **锚定 A1**：「新创作者首发视频在 24 小时内获得曝光量 **P10 ≥ 50 次**，同批新创作者曝光 **基尼系数 ≤ 0.6**（对应假设 A1）。」`[F4-§5.2]`
2. **锚定 A4**：「在无引导条件下，新用户首次上传**任务完成率 ≥ 80%**，**中位耗时 ≤ 90 秒**，**人工求助率 ≤ 5%**（对应假设 A4）。」`[F4-§5.2]`
3. **锚定 A2**：「冷启动用户（历史行为 < 3 条）首刷前 10 条**兴趣标签命中率 ≥ 60%**，**20 秒内退出率 < 40%**（对应假设 A2）。」`[F4-§5.2]`
4. **护栏条款（必须同时写入）**：「上述三项达标不得以恶化为代价：**举报率 < 0.5%**、**单创作者在单条 feed 内 ≤ 2 条**、**7 天内已看不重复推荐**、**人均观看时长不下降**（对应护栏假设 A3）。」`[F4-§5.2]`
5. **本单新增（锚定北极星）**：「北极星指标 **NS = 创作者次周留存率 × 人均有效观看时长**，计算口径见本单 §4.4；分子分母定义冻结后方可启动效果实验；口径变更须同步修订本条款。」`[本单 §4.4]`
6. **本单新增（锚定 G1）**：「观众侧 **P0 负反馈出口**（`dislike`/`report` 最小实现）为 MVP 必交付项，缺口状态须在 PRD 的覆盖核对表中显式登记（当前为未实现）。」`[F4-§6 G1]`

### 6.4 必须前置的测量基础设施（否则本策略不可验证）

按依赖顺序（继承 PRO-4 §4.7，本单加注策略层理由）：

1. **最小鉴权 + 限流** —— 无此则 `like/skip` 埋点可被脚本刷量，A3/A8 的实验结论不可信，**而本策略的 D2（公平可度量）正是建立在 A1 的 Gini 判据之上**。
2. **首刷标记 / 退出事件 / 注册来源埋点** —— 无此则 A2 不可测，而 A2 是观众侧留存的唯一引擎。
3. **兴趣标签 ground truth（注册期可选 3 选，并测跳过率 < 40%）** —— 无此则 A2 判据无法计算。
4. **负反馈 API（`dislike`）与创作者侧曝光可见位** —— A6/A5 的前置，也是 D3（可解释）在观众侧的最小兑现。
5. **口径冻结（view / exposure / 完播 / 有效播放）** —— 无此则 §4.2 的广告门槛无法计算，且跨平台比较会失真。
