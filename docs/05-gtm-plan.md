# 短视频平台 · GTM 方案与冷启动增长策略

> 前置输入：`01-competitive-analysis.md`、`02-user-research-personas.md`、`04-mvp-prd.md`
> 核心约束：用户渗透率 95.4%、年增速 0.8% —— **没有自然增量，所有增长必须是抢来的**

---

## 一、战略前提：别用抖音的武器打抖音

竞品调研得出的三条硬约束：

1. **流量池赛马机制已经把头部效率拉满**。抖音「陌生人流量池阶梯晋级」+「用户行为概率 × 行为价值权重」的推荐公式，是多年数据与工程积累的产物。新平台在通用品类上用同一套打法，等于在对手的主场打对手最擅长的仗。
2. **创作者分成模式已被验证**。YouTube Shorts 的 45% 固定广告分成、视频号「评论区广告分成」是清晰标杆；而**纯补贴模式已被证伪**（买来的创作者没有留存动力）。
3. **分发路径可以差异化**。视频号证明，用社交关系链绕开算法正面竞争是可行的——虽然从零起盘无法直接复制，但它说明"分发本身"是可以做差异的维度。

**因此 GTM 的战略姿态是：不在"更好看"上竞争，在"更容易被看到"上竞争。**

---

## 二、定位与命名

### 2.1 定位陈述

> 对于**刚起步的垂直品类创作者**（美食、宠物、健身、读书、手作等），
> 他们受够了在通用平台发 20 条只有 3 条被看到，
> 本平台是一个**保证首发光有曝光、并用数据告诉你为什么**的短视频社区。
> 不同于抖音和快手，我们不承诺"爆"，我们承诺"不白干"。

### 2.2 三个候选命名方向

| 命名 | 含义 | 适用性 |
|---|---|---|
| **光见**（或 "First Light"） | "发出来就被看见" | ✅ 直接对应核心承诺，冷启动期最贴切 |
| **苗圃** | 创作者是苗，平台是圃 | ✅ 强调培育而非赛马，适合长期品牌 |
| **垂类名 + 号**（如「美食号」） | 品类即品牌 | ⚠️ 天花板低，跨品类扩张受阻 |

**推荐「光见」**：一个词说清差异化，且不锁死品类。

### 2.3 Slogan 候选

- 主：「首发不白干」
- 备：「你的第一条，就有人看」
- 品牌向：「先被看见，再被喜欢」

## 三、冷启动增长：三阶段飞轮

### 阶段 1：供给侧单点突破（0 → 1,000 创作者）

**核心洞察**：冷启动期平台没有任何消费价值（内容池是空的），所以**唯一的增长引擎是供给**。不要去买流量，要去做"人肉推荐算法"。

| 动作 | 具体做法 | 目标 |
|---|---|---|
| 定向挖人 | 从抖音/小红书的**腰部垂类创作者**（1万-10万粉）中筛选被算法压制的群体 | 200 人种子池 |
| 一对一承诺 | 承诺「首条视频保底曝光 500」并**用真实数据兑现** | 建立口碑 |
| 数据透明 | 开放每条视频的曝光/完播/来源构成（头部平台不给的） | 差异化体验 |
| 陪跑期 | 前 10 条视频每条给人工反馈报告 | 建立情感绑定 |

**关键机制设计（产品侧支撑）**：
- 曝光保底 = 推荐引擎的 `fallback` 路由 + 新视频保护期（不进淘汰池，见 `03` 第 6 章「流量池晋级」）
- 打散上限（单创作者 2 条/feed）确保腰尾部不被头部挤压

**阶段验收**：1,000 名创作者 × 平均 3 条视频 = 3,000 条内容，且**首发 24h 曝光量 P10 ≥ 50**（对应 H1 假设）。

### 阶段 2：消费侧跟随供给（1,000 → 100,000 DAU）

**核心原则**：等供给密度够高（垂直品类内有足够可消费内容）再投消费。过早投放等于把用户带到空旷的房间。

| 渠道 | 打法 | 为什么有效 |
|---|---|---|
| 垂类社群 | 美食/宠物/健身微信/QQ 群，用"本地探店"类内容切入 | 内容与场景天然匹配，转化率高 |
| 创作者自带流量 | 创作者在自己的抖音/小红书简介放"完整版在 XX" | 借对手的流量池导流，成本极低 |
| 话题挑战 | 针对垂类做"7 天打卡"类挑战，形成内容密度 | 制造平台内自循环，不依赖外部投放 |
| SEO / 站外分发 | 视频同步生成可被搜索引擎收录的落地页 | 长尾流量 |

**关键机制**：
- **社交冷启动**（借鉴视频号）：新用户在无兴趣画像时，优先用好友关系链信号填充前 10 条，而非纯热门。这是**绕开算法能力差距的最有效手段**。
- **分享回流闭环**：分享链接落地页直接消费，不强制注册；消费 3 条后再引导注册。降低分享拦阻力 = 提高分享率 = 更多社交信号。

**阶段验收**：次日留存 ≥ 25%、人均日观看时长 ≥ 25 分钟、分享率 ≥ 3%。

### 阶段 3：创作者经济闭环（商业化）

| 变现方式 | 设计 | 依据 |
|---|---|---|
| 固定比例广告分成 | 平台广告收入按固定比例分给创作者（参照 Shorts 45%） | 清晰可预期，优于黑盒补贴 |
| 垂类商单撮合 | 本地商家 × 垂类创作者，平台抽佣 | 垂直平台的天然优势（通用平台做不深） |
| 不做 | ❌ 打赏（依赖头部效应）、❌ 会员订阅（早期用户量不足） | 避免分散资源 |

**护栏**：创作者曝光 Gini 系数 > 0.6 时触发流量再平衡。理由——**如果创作者经济收益高度集中，平台就从"苗圃"退化成了"小号抖音"，差异化叙事崩塌**。

## 四、增长飞轮（自增强循环）

```
      ① 保底曝光承诺
            │
            ▼
   ② 腰部垂类创作者入驻
            │
            ▼
   ③ 垂类内容密度上升
       （新视频有标签邻居可被召回）
            │
            ▼
   ④ 推荐流对垂类用户变准（tag 路由生效）
            │
            ▼
   ⑤ 消费时长与留存上升
            │
            ▼
   ⑥ 创作者获得真实反馈 → 继续供给 ──┐
            │                        │
            ▼                        │
   ⑦ 口碑扩散带来新创作者 ───────────┘
```

**飞轮的关键耦合点在第 ③→④ 步**：内容密度不足时，`tag` 召回路由无邻居可召，推荐质量塌陷。所以**阶段 1 必须按垂类而非按总量做供给**——1,000 个美食创作者比 1,000 个跨品类创作者价值高得多。

## 五、竞争应对（Battlecard）

| 对手 | 他们的优势 | 我们的打法 | 不能做什么 |
|---|---|---|---|
| **抖音** | 算法最强、内容最全、变现成熟 | 不拼算法精度，拼**腰部创作者的确定性感受**；用数据透明做差异化 | ❌ 不要试图在通用内容上比推荐效果 |
| **快手** | 私域强、老铁经济、中长尾扶持 | 我们的"打散机制"与它的普惠逻辑同源但更彻底；可对标其基尼系数做 PR | ❌ 不要攻击其社区文化 |
| **视频号** | 社交关系链、微信入口 | 学习其社交冷启动；但强调我们的**创作者工具与数据开放**优于它 | ❌ 不要与其争微信场景内的社交分发 |
| **小红书** | 图文+视频、种草心智、垂类深 | 我们与其最接近，需在**视频优先**与**创作者分成**上做出明确差异 | ❌ 不要做成"视频版小红书"的模糊定位 |
| **B站** | 中长视频、社区氛围 | 我们是短视频，时长上限 3 分钟，与之不构成直接竞争 | — |

## 六、指标看板

### 北极星指标

**创作者次周留存率 × 人均有效观看时长**

为什么这么定：单看 DAU 会掩盖"只有消费没有供给"的空心化；单看创作数会掩盖"发了没人看"的挫败。这个乘积同时约束供需两侧，**任何一侧掉链子都会立刻显形**。

### 分层指标

| 层级 | 指标 | 目标（阶段 2 末） |
|---|---|---|
| 供给 | 周活跃创作者数 | ≥ 5,000 |
| 供给 | 创作者次周留存率 | ≥ 40% |
| 供给 | 首发 24h 曝光量 P10 | ≥ 50 |
| 消费 | DAU | ≥ 100,000 |
| 消费 | 人均日观看时长 | ≥ 25 min |
| 消费 | 次日留存 | ≥ 25% |
| 消费 | 完播率 | ≥ 45% |
| 生态 | 创作者曝光 Gini | ≤ 0.6 |
| 生态 | 举报率 | ≤ 0.5% |
| 生态 | 跳过率 | ≤ 40% |

### 反指标（触发即回滚）

| 反指标 | 阈值 | 动作 |
|---|---|---|
| 举报率 | > 1% | 回滚最近一次排序权重变更 |
| 创作者 Gini | > 0.7 | 强制提升探索流量比例 |
| 跳过率 | > 50% | 检查是否存在内容与用户画像严重错配 |

| 周次 | 里程碑 | 关键动作 |

## 八、最大的风险与对冲

| 风险 | 概率 | 影响 | 对冲 |
|---|---|---|---|
| **保底曝光的成本失控** | 中 | 高 | 保底额度分级（按创作者等级），并用 `fallback` 路由的天然流量而非付费流量兑现 |
| **垂类太小做不出飞轮** | 中 | 高 | 同时布局 2-3 个相邻垂类（如美食+探店+本地生活），共享用户画像 |
| **头部创作者虹吸** | 高 | 中 | 创作者打散机制（单 creator 2 条上限）+ Gini 护栏 |
| **算法权重未经校准，早期推荐质量差** | 高 | 高 | 冷启动期**降低个性化权重、提高内容匹配与保底权重**，宁可粗糙也不要错配 |
| **对手跟进"创作者保底"策略** | 低 | 中 | 我们的护城河是**机制化的公平（算法层面的打散与 Gini 约束）**，大平台受既得利益制约难以真正跟进 |
