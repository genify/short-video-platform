## 0. 阅读指引与证据强度定义

本文档回答四个问题：**服务谁 → 他们需要什么 → 我们的假设是什么 → 用最便宜的方式如何否证它们**。

**证据强度定义（全文强制使用，不得把观点当事实）**

| 等级 | 名称 | 判定标准 | 引用规则 |
|---|---|---|---|
| **E4** | 强证据 | 本产品可复现的系统行为/代码级事实（有实现 + 回归测试覆盖），或官方一手文档、上市公司财报且口径明确 | 可直接作为事实陈述 |
| **E3** | 中等证据 | 公开可核实的一手/权威二手数据（官方文档、财报、大样本监测），但与目标人群或场景存在口径差 | 可作事实，但必须标注口径差 |
| **E2** | 弱证据 | 第三方运营经验总结、自媒体拆解、二手转述、口径不一致的行业报告 | 只能作为"待核实线索"，必须标注来源与「未核实」 |
| **E1** | 无证据 | 团队推断、类比、直觉，无任何外部或内部数据支撑 | **禁止作为事实引用**，只能以"假设/待验证"措辞出现 |

**可证伪陈述模板**：`在【范围/人群】下，【指标】达到【阈值】，当【反向条件】出现即判定为假。`

|---|---|---|---|---|
| **A. 泛娱乐观众** | 林小满（Scroll-Native, 19）、王建国（Silver-Newcomer, 58） | 消费为主，供给可忽略 | 时长与活跃度基本盘 | ✅ 是（留存目标） |

### 1.1 细分 A｜泛娱乐观众（Entertainment Viewers）

**边界定义**：核心动机是"打发碎片时间 + 情绪价值"，自身发布频率 < 1 条/月，在平台内不承担供给。

**JTBD（Job Story 格式）**
- 主群（18–30 岁）：**当我**处于碎片化、无目的的空闲时（课间/通勤/睡前），**我想要**用不费力的方式连续获得不重复、不踩雷的内容，**以便**填满无聊时间并拿到社交谈资与情绪出口。
- 子群（50–59 岁"新银发"）：**当我**想看看同龄人和同兴趣的内容、顺手记录我的生活时，**我想要**用大字号、少步骤、能听懂的方式完成，**以便**不觉得自己被时代落下。

**典型场景**：① 无目的滑动，前 3 秒决定划走；② 从微信群分享落地页进入（无 App 安装意愿）；③ 银发用户晚间 60–120 分钟长时段连续观看。

**需求强度证据**
- 人群规模与时长：E3 —— 中国短视频用户 10.74 亿、使用率 95.4%、人均单日 163 分钟（来源 S1，行业报告转述，原始问卷口径未公开）；50–59 岁占 20.9%（S1/S5）。
- 痛点强度："越刷越重复/同质化疲劳"：**E2**（行业媒体与用户吐槽转述，未核实）；"新平台没人玩所以不敢装"：**E1**（团队推断）。

**对 MVP 的具体含义**：推荐流是唯一留存引擎；变量是**首刷命中**（前 10 条）与会话内**多样性**，而不是注册流程的丰富度。

### 1.2 细分 B｜兴趣内容创作者（Interest-based / Side-hustle Creators）

**边界定义**：有明确的表达或变现动机，创作发生在"业余时间"（夜间/周末/带娃间隙），工具熟练度中等偏低，对流量确定性极度敏感。

**JTBD**
- **当我**想验证"我能不能靠内容获得回报"时，**我需要**用低成本走完整条"拍摄→发布"链路并拿到可解释的流量反馈，**以便**在结果不确定的情况下仍有继续投入的理由。

**典型场景**：① 晚上 22:00–24:00 剪完一条发布；② 发布后每 5 分钟刷新数据页；③ 在评论区维护客户关系（刘阿妹）；④ 因"昨天爆今天零播放"而怀疑账号被限流。

**需求强度证据**
- "冷启动流量不确定、爆不爆像玄学"：**E2** —— 来源为创作者社区与行业自媒体转述（docs/01 第 3.3 节流量池阈值为第三方观测，已标注未核实）。
- "需要确定性高于需要更多功能"：**E1**（推断；这正是本 MVP 定位所押注的赌注，即假设 A1，必须实验否证）。
- 供给侧竞争事实：日均上传 > 1.3 亿条（S1，E3/E2）→ "发得出去不是问题，被看见才是问题"。

**对 MVP 的具体含义**：发布链路 ≤3 步 + 发布后**即时曝光反馈**；把"确定性"做成产品机制，而不是靠运营承诺。

---

### 1.3 细分 C｜垂类 / 本地创作者（Vertical & Local Creators）

**边界定义**：把内容当生意经营，追求可测量的回报（粉丝/到店），对规则透明度与工具专业度挑剔；发布频次两端分化（日更 vs 每周 1–3 条）。

**JTBD**
- 垂类（李欣）：**当我**已把创作当成职业时，**我需要**稳定可预测的分发与透明的规则，**以便**把收入与影响力当成可经营的资产。
- 本地（张伟）：**当我**想让同城顾客知道我的店时，**我需要**本地精准曝光与"到店"闭环数据，**以便**把线上流量变成确定的客流。

**典型场景**：① 日更测评/游戏内容并跨多平台分发；② 后厨拍菜品 + 挂优惠；③ 用核销数据复盘投放效果。

**需求强度证据**
- "垂类/本地是新平台可切入的差异化切口"：**E1** —— 来自 docs/01 结论 5 的推断（生态位分析），不是用户证据。
- "创作者愿意迁移/首发到新平台"：**E1（无证据）** —— 这是本细分最大的认知空白，已写成假设 **A7**。
- 本地到店转化 2%、银发任务完成率 70% 一类阈值：**E1**（团队设定值，需灰度校准，禁止对外引用为行业基准）。

**对 MVP 的具体含义**：MVP Non-Goals 明确排除 LBS、电商、支付（docs/04 §1.3），因此本细分在 MVP 阶段**只作为内容供给质量与标杆来源**，其变现类需求（挂载、佣金、到店核销）**不在本 MVP 的验证范围**，转由 PRO-5（策略）与后续迭代承接。

## 2. 需求地图（Needs Map）

优先级口径：**P0 = MVP 必须满足（缺失即流失）｜P1 = MVP 内可做且构成差异化｜P2 = MVP 后**。
优先级来源为 KANO 分层（docs/02 §5）与本次风险排序的合成结论。

### 2.1 观众侧

| 阶段 | 需求 | 痛点（用户语言） | 优先级 | 证据强度 | MVP 承载情况 |
|---|---|---|---|---|---|
| **发现** | 首刷命中兴趣（前 10 条） | "前 20 条还不错，后面全是同一类" | **P0** | E2（同质化抱怨） | ✅ 已实现：`tag`/`cf` 召回 + 冷启动兜底（`/api/feed` 返回 `cold_start`） |
| **发现** | 不连续同类（会话内多样性） | "刷十条都一个样，那不是推荐，是复读机" | **P0** | E2 | ✅ 已实现：MMR λ=0.7 + 单创作者 ≤2 条 |
| **发现** | 秒开 / 不卡顿 / 弱网可播 | "卡一下我就划走了" | **P0** | E1（体验常识） | ✅ 已实现：HTTP Range 206（`/api/videos/{id}/file`） |
| 发现 | 话题/搜索可持续追某主题 | "想找某个话题的持续内容时没有引导" | P1 | E1 | ❌ 未实现（MVP 范围外） |

### 2.3 需求地图三条判读（必须与 PRD 对齐）

1. **P0 需求实现率**：观众侧 P0 共 5 项，已实现 3 项、未实现 1 项（负反馈）、部分实现 0 项；创作者侧 P0 共 3 项，已实现 2 项、待验证 1 项（≤3 步发布的可用性）。→ **唯一"硬缺口"是负反馈出口**，且它是 P0。
2. **机会窗口集中在"发布 → 反馈"环节**：竞品对新账号的冷启动普遍不友好（docs/01 §3.3–3.4），这是本 MVP 相对抖音/TikTok 最可行、成本最低的差异化点（与 docs/02 §4.1 结论一致）。
3. **需求地图与 MVP 范围存在一处系统性错配**：创作者侧"创作"阶段需求（模板、剪辑、进度、断点续传）被 PRD 明确排除，但细分 B/C 的痛点描述大量落在这里。→ 结论：MVP 不可能靠"创作体验"赢，**只能靠"发布成功率 + 曝光确定性"赢**；对外话术与验收标准必须锚定后者（已写入 §5）。

## 3. 假设清单（Assumption Map）

共 8 条，全部改写为**可证伪陈述**。判定优先级 = 影响度 ×（证据强度倒数）。

### 3.1 假设明细

**A1｜新创作者首发曝光的确定性**（影响度：**高**｜证据强度：**E2**）
- 陈述：在无付费推广的前提下，新创作者的首条视频在 24 小时内获得的曝光量 **P10 ≥ 50 次**，且同批新创作者之间曝光量的**基尼系数 ≤ 0.6**。
- 判据：24h 后统计首发曝光 P10 与基尼系数；`P10 < 50` 或 `Gini > 0.6` → 判定为假。
- 依据：竞品冷启动池观测值 500–5000 曝光为第三方运营经验（E2，未核实，docs/01 §3.3）；"新号不友好"是行业共识而非本产品数据。
- 若被证伪：产品定位（docs/04 §1.1"让新创作者的第一条视频拿到确定曝光"）失去支撑，需转向"消费侧体验"叙事。
- 可测性：✅ 现有 MVP 可测（`video_stats` 反规范化计数器 + `/api/videos`）。

**A2｜冷启动个性化命中**（影响度：**高**｜证据强度：**E1**）
- 陈述：新用户（历史行为 < 3 条）首刷前 10 条中，**兴趣标签命中率 ≥ 60%**，且 **20 秒内退出率 < 40%**。
- 判据：埋点统计首刷前 10 条命中率与退出率；`命中率 < 60%` 或 `退出率 ≥ 40%` → 判定为假。
- 依据：无一手数据。冷启动效果依赖真实行为日志，MVP 尚未接入真实流量（E1）。
- 若被证伪：需引入注册期兴趣选择（3 选）或首刷编辑策展池；docs/04 §3.3 冷启动策略需重写。
- 可测性：⚠️ 需补埋点（当前无"首刷"标记、无退出率、注册期无兴趣标签作为 ground truth）。

**A3｜多样性重排不损伤短期消费**（影响度：**中高**｜证据强度：**E4（系统行为）/ E1（真实消费）**）
- 陈述：开启 MMR 多样性重排（λ=0.7）+ 单创作者 ≤2 条后，实验组人均观看时长 **≥ 对照组（纯相关性排序）× 0.95**，且单次会话内**连续同类条数 ≤ 3**。
- 判据：A/B 两组人均观看时长比值 `< 0.95` 或同类连续 `> 3` 条 → 判定为假。
- 依据：离线可复现（docs/03 手算示例 + 86 项回归测试，E4）；"不损伤真实消费"仅有设计推理（E1）。
- 若被证伪：λ 上调至 0.85 或改为类目级软打散；接受一定同质化换取时长。
- 可测性：✅ 可测（`MMR_LAMBDA`、`CREATOR_CAP_PER_FEED` 均在 `server/config.py`，支持 seed 分桶 50/50）。

**A4｜免引导即可完成首次上传**（影响度：**高**｜证据强度：**E1–E2**）
- 陈述：在**无引导、无帮助文档**的条件下，新用户能在 3 步内完成首次上传，**任务完成率 ≥ 80%**、**中位耗时 ≤ 90 秒**、**人工求助率 ≤ 5%**。
- 判据：可用性测试（8–10 人，含 ≥3 名 50 岁以上）；任一阈值未达 → 判定为假。
- 依据：银发/宝妈"上传复杂"为二手转述（E2）；"无需引导"是 PRD 的隐含假设，从未被测试（E1）。
- 若被证伪：必须增加引导层或"极简模式"，PRD 的 P0 列表需改为"引导 + 3 步"。
- 可测性：✅ 可用性测试可测（需真实可点 UI；当前仅有 API）。

**A5｜发布后即时曝光反馈降低焦虑、提升复访**（影响度：**中**｜证据强度：**E1**）
- 陈述：向新创作者展示"已推送给 X 人"（X 为真实曝光数），可使**发布后 10 分钟内查看数据的比例 ≥ 40%**，并使**次日回访率相对提升 ≥ 5 个百分点**，同时投诉率不上升。
- 判据：A/B；`10 分钟回访率 < 40%` 或 `次日回访提升 < 5pp` → 判定为假；若投诉率上升则判定为**有害**。
- 依据：无任何外部数据支持该因果关系（E1）；存在反向风险——即时反馈可能放大"5 分钟只有 3 次曝光"的焦虑。
- 若被证伪或被判定有害：改为"周报式聚合反馈"（降低刷新频率，避免制造焦虑）。
- 可测性：❌ 需新功能（通知/展示位）。

**A6｜负反馈与兴趣调控会被真实使用**（影响度：**中**｜证据强度：**E1**）
- 陈述：≥15% 的月活用户会在 30 天内至少使用一次"不感兴趣"或兴趣调控，且使用者的次周留存 ≥ 未使用者。
- 判据：上线最小实现（仅记录 `dislike` 事件，不训练模型）后统计；`使用率 < 5%` → 判定为假（放弃继续投入）；5%–15% 保留最小实现。
- 依据：E1。历史经验表明这类显式调控入口的使用率通常远低于产品经理预期（团队经验，非数据）。
- 若被证伪：砍掉调控 UI，改为隐式信号（skip/快滑）+ 内容化的"算法说明"。
- 可测性：❌ 需新功能（当前**无** dislike/report API，且需求地图中该项为 P0 —— 缺口见 §6）。

**A7｜垂类创作者愿意把本平台作为"首发"而非"分发补充"**（影响度：**高**｜证据强度：**E1（无证据）**）
- 陈述：招募的 20 名垂类创作者中，**≥50%** 在 30 天内于本平台首发（早于其他平台）**≥2 条**内容，且 **30 日留任 ≥ 50%**。
- 判据：种子创作者计划实测；`首发比例 < 50%` 或 `留任 < 50%` → 判定为假。
- 依据：无证据。竞品研究只证明生态位差异（E3），不证明迁移意愿（E1）。
- 若被证伪：定位改为"多平台分发工具"（把核心痛点从"被看见"改为"省时间"），属于重大战略改写。
- 可测性：⚠️ 需线下招募 + 人工记录（无产品内埋点）。

**A8｜5 路召回配额 + 线性权重优于单路基线**（影响度：**中**｜证据强度：**E4（代码事实）/ E1（效果）**）
- 陈述：在真实流量下，当前配额与权重（0.45/0.20/0.15/0.10/0.10）的 feed 完播率，相对"单一标签召回"基线**提升 ≥ 10%（相对值）**。
- 判据：灰度 A/B；相对提升 `< 10%` → 判定为假，回退到更简单基线。
- 依据：权重全部为行业经验初值（docs/04 §六 P0 已知限制）；离线手算与回归测试只证明实现正确性，不证明效果（E4 → 效果侧 E1）。
- 若被证伪：回退到单路 + 后置规则排序，避免在无数据阶段过度工程。
- 可测性：✅ 可测（`server/config.py` 可调权重 + seed 分桶）。

## 4. 实验设计（针对最高风险假设的最简验证）

**总原则**：先用"零成本或极低成本"手段否证高风险假设，再投入工程。执行顺序按"成本/信息量比"排序，而非按假设编号。

### 4.1 实验总览

| 编号 | 验证的假设 | 方法 | 最小样本 | 工期 | 增量成本 | 前置依赖 |
|---|---|---|---|---|---|---|
| **E-A4** | A4 | 主持式可用性测试（真实可点 UI） | 8–10 人（先做 5 人） | 3–5 天 | 低（招募 + 礼品） | 需上传页可点击原型 |
| **E-A1** | A1、A7 | 落地页假门测试（3 变体）+ 种子创作者队列 | 300–500 访客；20 名创作者 | 10–14 天 | 中（投放预算） | 落地页 + 留资表单 + 兑现机制 |

### 4.2 E-A4｜可用性测试（最先做，3–5 天）

**目的**：否证"免引导即可完成首次上传"。这是**成本最低、信息量最高**的实验，且失败后果最严重（漏斗断裂 = 供给断裂）。

**招募配额（共 8–10 人）**：≥3 名 50 岁以上（细分 A 的银发子群）、≥3 名 30–39 岁宝妈或小微商家（细分 B/C）、≥2 名副业创作者（细分 B）。筛选提问（screener，必须问过去行为而非意愿）：
1. 过去 30 天，你在手机上发布过几条短视频？（要求 ≥1；0 条者排除）
2. 你上次发布时用了什么工具（App 内 / 剪映 / 其他）？
3. 你的出生年份？（用于年龄配额，不用于筛选偏好）

**任务脚本（不提示路径）**
- T1：请上传并发布一条你手机里现有的视频。
- T2：请改一下文案，让它带上"美食"这个话题。
- T3：请告诉我，怎样才能让系统少给你推"宠物"类内容。

**访谈要点（开放式，禁止引导）**
1. 请讲讲你上一次在手机上发布视频的完整过程，从打开手机开始。
2. 刚才哪一步让你停下来了？你当时在想什么？
3. 如果没有人教你，你能自己找到"发布"这个动作吗？
4. （T3 后）如果找不到入口，你平时是怎么让推荐流变"干净"的？
- **禁忌问题（会导致无效数据）**：❌"你觉得简单吗？"（引导）❌"你会用这个功能吗？"（意愿 ≠ 行为）❌"你喜欢这个设计吗？"（社交礼仪式回答）。

**记录与成功判据**

| 指标 | 阈值 | 测量方式 |
|---|---|---|
| 任务完成率 | **≥ 80%**（8/10） | 未完成 = 需要主持人协助才发布成功 |
| 中位耗时（T1） | **≤ 90 秒** | 从"请开始"到发布成功 |
| 人工求助率 | **≤ 5%** | 主动提问/请求帮助的次数占比 |
| 严重可用性问题 | 0 个（阻断级） | 观察记录 + 出声思维 |

**提前结束规则（Nielsen 5 人定律）**：前 5 人完成率 ≥ 90% 且无阻断级问题 → 提前结束，进入 E-A1。
**失败分支**：完成率 < 80% → 定位首个断裂步骤，产出"引导层 or 极简模式"两个候选方案，再测 5 人；**不允许在未修复前进入 E-A2 的规模化埋点。**

### 4.3 E-A1｜落地页假门测试 + 种子队列（10–14 天）

**目的**：在投入产品开发前，用最小成本同时测试 A1（外部是否相信"保底曝光"值得迁移）与 A7（是否愿意首发）。

**落地页设计（3 变体，同一流量池随机分流）**

| 变体 | 主标题 | 价值主张 | 用来分离的动机 |
|---|---|---|---|
| V1「确定性」 | 把「能不能被看见」变成一条明写的规则（**机制类替代句**，替代已禁用的原句「你的第一条视频，我们保证有人看」） | 新号首发 24h 内 ≥50 次真实曝光 + 可解释的流量归因（**T0 起才可使用**） | 被看见 |
| V2「收益透明」 | 规则写在明面上，不再猜算法 | 分成比例公开 + 每条的推荐理由可见 | 被回报 |
| V3「省时间」 | 一次上传，多平台分发 | 一键分发 + 统一数据看板 | 省成本 |

> **相位纪律（PRO-15 同步，本节必读）**：本表的**主标题 / 价值主张是设计口径**；实际投放文案以 `marketing/landing/copy_pack.json` 的 `assets.recruit.<变体>.pre_t0` / `.t0` 两臂为准（`docs/08` §4.3、`copy_pack.json` `rules[0..3]`）。
> ① T0 前**不得出现任何结果承诺，即使没有数字**。V1 原主标题「**你的第一条视频，我们保证有人看**」属结果承诺类，本次**已就地替换**为机制类表述「把「能不能被看见」变成一条明写的规则」；该原句**保留在案**并标注为 `pre_t0` 禁用 —— **T0 起才可使用**（词表 `TG-06` 覆盖）。`pre_t0` 臂的现行对应文案为 `copy_pack.json` `assets.recruit.V1.pre_t0.h1`。
> ② 价值主张列的「≥50 次真实曝光」属 `docs/05` §3.5 白名单数字 → 同样 **T0 起才可使用**（`docs/05` §0.3）。
> ③ 本文档内的「**保底曝光**」是 A1 假设的历史代号，属 `docs/05` §0.2 **已删除的旧口径**（词表 `HB-01`）—— **仅限内部使用，不得进入任何对外文案**。
> ④ 产品机制的统一措辞为「**把首发的曝光规则写成产品里的一条硬约束**（具体数值规则开放时一并公开）」。
> ⑤ 本文档出现的 P10 ≥ 50 / 基尼系数 ≤ 0.6 / ≥50% 等数值均为**假设的判定阈值（内部）**，不是对外承诺；对外只允许 `docs/05` §3.5 白名单中的**三项数字**（该白名单共 5 项，另两项为「推荐理由可见」与「分成规则先公开后结算」），且 **T0 起才可使用**。


**转化事件与判据**

| 事件 | 定义 | 判据 |
|---|---|---|
| `page_view` | 落地页浏览 | —— |
| `cta_click` | 点击"申请创作者名额" | —— |
| `form_submit`（主判据） | 留下手机号/微信号 | **留资转化率 ≥ 8%**；且 **V1 − max(V2,V3) ≥ 3pp** 才可判定"曝光确定性"是主驱动因素 |
| `first_upload` | 收到邀请后 7 天内完成首发 | **≥ 50%** 留资者完成（支持 A7 的供给侧意愿） |
| `24h_exposure` | 首发 24h 曝光量 | **P10 ≥ 50 且 Gini ≤ 0.6**（A1 的真实判据） |

**成功/失败判定**
- A1：以 `24h_exposure` 的 P10 与基尼系数为准（方法判据同 A1）。假门转化率**不能**替代 A1 —— 落地页只证明"宣传被相信"，不证明"承诺被兑现"。
- A7：以 `first_upload` 比例与 30 日留任为准。
- 若 V1 与 V2/V3 差值 < 3pp → 说明"确定性"不是主驱动，定位叙事需由 PRO-5 修订（这是本次实验最有价值的负向结论之一）。

**伦理红线（必须遵守）**：假门必须在留资后 **7 天内兑现**（真发保底曝光），否则属欺骗性设计，禁止用于对外投放；留资页必须写明收集目的、保留期与退出方式；仅收集最低必要信息（一个联系方式字段）。

### 4.4 E-A2｜首刷命中（定量 + 定性并行，7 天）

**定量（灰度 50–100 名新用户）**

| 指标 | 定义 | 判据 |
|---|---|---|
| 兴趣命中率 | 首刷前 10 条中命中"注册时选择的兴趣标签"的比例 | **≥ 60%** |
| 20 秒退出率 | 进入 feed 后 20 秒内离开的比例 | **< 40%** |
| 前 3 条跳过率 | 前 3 条发生 skip 的比例 | 参考值 < 50%（无硬阈值，用于归因） |
| 标签选择跳过率 | 注册期兴趣选择的跳过比例 | **< 40%**（否则"必填兴趣"方案直接否决） |

**关键设计说明**：命中率需要 ground truth，因此本实验**同时测试"注册后选 3 个兴趣标签"这一 PRD 待定项**。若标签选择跳过率 ≥ 40%，则"必填兴趣"方案被否证，A2 只能依靠行为推断（首刷之后才能个性化）。

**定性（5–8 人，1–2 天）**：向用户展示 3 组首刷样本（全热门 / 全标签匹配 / 混合多样性），让他们打分并排序。提问：
1. 这一组里哪几条你会看完？为什么？
2. 你上一次刷视频时，是哪一刻决定划走的？当时屏幕上是什么？
3. 刷到不感兴趣的内容时，你通常怎么办？

**失败分支（必须区分两种同症不同因的情况）**
- 命中率 < 60% → 算法/冷启动问题：引入首刷编辑策展池 + 强制多样性（MMR 从全库采样）。
- 20 秒退出率 ≥ 40% 但命中率正常 → **很可能是播放性能问题（首帧加载/白屏）**，应先修秒开再谈算法。错误归因会把工程资源投到错误的层。

### 4.5 E-A3 / E-A8｜护栏与权重 A/B（≥7 天，现成能力）

- 方式：`server/config.py` 的 `RANK_WEIGHTS`、`MMR_LAMBDA`、`CREATOR_CAP_PER_FEED` 可直接改配置；`/api/feed` 支持 `seed` 参数 → 用用户哈希分桶实现 50/50 分流，**无需改代码、无需上线新版本**。
- 判据：实验组人均观看时长 ≥ 对照组 × 0.95；单次会话同类连续 ≤ 3 条；次日留存不降。样本 ≥ 200 用户/组，覆盖至少 1 个完整周末。
- 权重组（A8）：① 当前权重；② 纯标签召回基线；③ 相关性加重版（`aff=0.60, pop=0.15`）。相对提升 < 10% 则维持简单基线。

### 4.6 E-A5 / E-A6｜假门与最小实现（7–30 天，需先补功能）

- **A5**：一半新创作者看到"已推送给 X 人"，另一半看到中性文案"发布成功"（X 必须为真实曝光数，禁止写死或夸大）。判据：10 分钟回访率 ≥ 40%、次日回访 +5pp、投诉率不上升。若回访率 < 25% 或投诉上升 → 判定为**有害**，改为周报式反馈。
- **A6**：上线最小 `dislike` 入口（仅记录事件类型，不训练模型）。判据：30 天使用率 ≥ 15% 继续投入；5–15% 保留最小实现；< 5% 砍掉 UI，仅保留埋点采样。


**必须先补齐的测量基础设施（否则部分假设无法测）**
1. **首刷标记与退出率埋点**（`cold_start=true` 已有，但缺"注册来源/首刷序号/退出事件"）。
2. **兴趣标签 ground truth**（注册期可选兴趣，或首刷后的隐式推断基线）。
3. **反作弊与鉴权**：当前 API **无鉴权、无限流**（docs/04 §四已知限制）。`like/skip` 埋点可被脚本刷量，**在任何效果实验前必须补齐**，否则 A3/A8 的实验结论不可信。
4. **负反馈 API**（`dislike`）与**创作者侧曝光可见位**（A5/A6 的前置）。

## 5. 结论：Top 3 必须验证的假设（供 PRD 直接引用）

### 5.1 Top 3 清单

| 排名 | 假设 | 可证伪陈述（可直接引用） | 判据 | 验证方式 | 建议时点 | 建议责任人 |
|---|---|---|---|---|---|---|
| **1** | **A1** 新创作者首发曝光确定性 | 新创作者首发视频 24h 曝光 **P10 ≥ 50 次**，且同批新创作者曝光**基尼系数 ≤ 0.6** | 任一不达即否证 | 落地产线 + 种子队列实测（E-A1） | D10–D17 | User Researcher + Experiment Designer |
| **2** | **A4** 免引导完成首次上传 | 无引导条件下首次上传**完成率 ≥ 80%**、**中位耗时 ≤ 90s**、**求助率 ≤ 5%** | 任一不达即否证 | 主持式可用性测试 8–10 人（E-A4） | D0–D3 | User Researcher |
| **3** | **A2** 冷启动个性化命中 | 新用户首刷前 10 条**兴趣命中率 ≥ 60%** 且 **20 秒退出率 < 40%** | 任一不达即否证 | 定性样本对比 + 灰度埋点（E-A2） | D7–D14 | Experiment Designer + Metrics Designer |

**Top 3 的选择理由**：三者同时满足"影响度 = 高"与"证据强度 ≤ E2"，且分别覆盖 MVP 的两项核心功能与产品定位的前提 —— A1 = 创作者侧（定位前提：确定性）、A2 = 观众侧（留存前提：命中）、A4 = 上传链路（供给前提：漏斗）。任何一条被证伪，PRD 的范围或定位都必须改写；其余假设（A3/A5/A6/A8）失败只影响参数与功能取舍，A7 属业务级假设（由 PRO-5/PRO-8 承接）。

### 5.2 给 PRD 的验收标准写法（可直接粘贴）

1. **锚定 A1**：「新创作者首发视频在 24 小时内获得曝光量 P10 ≥ 50 次，同批新创作者曝光基尼系数 ≤ 0.6（对应假设 A1）。」
2. **锚定 A4**：「在无引导条件下，新用户首次上传任务完成率 ≥ 80%，中位耗时 ≤ 90 秒，人工求助率 ≤ 5%（对应假设 A4）。」
3. **锚定 A2**：「冷启动用户（历史行为 < 3 条）首刷前 10 条兴趣标签命中率 ≥ 60%，20 秒内退出率 < 40%（对应假设 A2）。」
4. **护栏条款（必须同时写入）**：「上述三项达标不得以恶化为代价：举报率 < 0.5%、单创作者在单条 feed 内 ≤ 2 条、7 天内已看不重复推荐、人均观看时长不下降（对应护栏假设 A3）。」

### 5.3 需要立即行动的三件事（按优先级）

1. **补负反馈 API**：需求地图中观众侧 P0 需求"负反馈出口"当前**未实现**（§6 缺口 G1），它是 A6 的前置，也是留存的下限保障。
2. **补埋点与反作弊**：在启动任何效果实验前完成首刷/退出埋点与最小鉴权限流，否则实验数据不可信（§4.7）。
3. **先跑 E-A4**：3–5 天可完成、成本最低，且结果决定其余实验是否顺延（漏斗优先于算法）。

## 6. 需求 → MVP 实现覆盖核对（缺口清单）

核对基准：`server/`（86 项回归测试全绿，E4）与 docs/04 PRD §三。

| 缺口 | 需求（优先级） | 现状 | 影响 | 处置建议 |
|---|---|---|---|---|
| **G1** | 负反馈出口（观众侧 **P0**） | 无 `dislike/report` API，`skip` 仅作画像负权（`ACTION_VALUE.skip=-2`） | 用户无出口 → 用卸载代替；A6 无法验证 | **最高优先补齐**（最小实现即可） |
| G2 | 首刷/退出埋点（测量基础设施） | `cold_start` 标记已有；缺首刷序号、退出事件、注册来源 | A2 不可测 | 随 E-A2 一起补 |
| G3 | 鉴权与限流 | 未实现（PRD 已知） | 埋点可被刷量 → 效果实验不可信 | 任何 A/B 前必须补最小鉴权 |
| G4 | 发布进度/断点续传（创作者侧 P1） | 无 | 弱网/低配用户上传失败率不可控 | MVP 后可接受；需先量化失败率 |
| G5 | 即时曝光反馈（创作者侧 P1） | 无通知/展示位 | A5 不可测；创作者"瞎发"体感 | 假门验证通过后再开发 |
| G6 | 兴趣标签选择（A2 的 ground truth） | 无 | A2 判据无法计算 | 随 E-A2 补（并测试跳过率） |
| G7 | 可解释推荐的用户可见 UI（P1） | API 返回 `features`/`reason`，仅运营可见 | 用户信任无法建立；A6 部分不可测 | MVP 后；先做内容化说明 |

**结论**：需求地图中 P0 需求共 8 项，已完整实现 5 项、部分实现 2 项（≤3 步发布待可用性验证、互动入口无前端）、**未实现 1 项（G1 负反馈）**。G1 是全量需求中唯一的 P0 级硬缺口。

## 7. 方法与局限说明（不得省略）

1. **全部 Persona 均为假设型画像（E1）**：姓名与引语为典型化合成，非真实受访者陈述；本文档的所有定性结论必须通过 §4 的一手验证才能升级为"事实"。
2. **二手数据标注**：引用行业数据（10.74 亿用户、95.4% 使用率、163 分钟/日、日均 1.3 亿条上传）为第三方报告转述，原始问卷口径未公开；流量池阈值（500–5000 曝光、完播率 ≥40%）为第三方运营经验，属"未核实"。**禁止在任何对外材料中把 E2 数据当作官方事实引用。**
3. **阈值均为待校准的假设值**（P10 ≥ 50、Gini ≤ 0.6、≥60%、≥80%、≤90s、15%/5% 等）：本文档给出的所有数值是**判定门槛**，不是行业基准，需在灰度后用真实分布校准。
4. **样本量限制**：可用性测试 8–10 人只能发现约 80% 的严重可用性问题，不能外推为总体比例；定性结论只用于发现假设，不用于确认假设。
5. **因果性限制**：A/B 只能验证"是否改变"，不能解释"为什么"；对归因有争议的结果需配合定性访谈交叉验证。
6. **本计划不含执行预算与合规审批**：受访者招募、个人信息（手机号/微信）收集需告知同意、最小化收集与最短保留期；涉及未成年人的内容需额外审查。
