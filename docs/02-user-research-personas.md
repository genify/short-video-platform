## 0. 摘要（TL;DR）

1. **市场已进入存量竞争阶段**：中国短视频用户规模约 10.74 亿人、使用率 95.4%，同比增速仅约 0.8%，人均单日使用时长 163 分钟。这意味着新平台**无法靠"拉新"取胜**，必须在"用户时长份额"和"细分场景"里找切口。
2. **用户需求正从"看得爽"转向"被看见 + 被回报"**：创作者侧的核心焦虑是**冷启动流量不确定**与**发布成本高**；消费侧的核心焦虑是**内容同质化与算法疲劳**。上传体验与推荐流质量是决定留存的"双引擎"。
3. **MVP 应聚焦两类核心人群**：① 有明确表达/变现动机的**轻创作者**（副业创作者、宝妈、本地商家）；② 有强内容消费动力的**年轻娱乐用户**与**新银发人群**。推荐流要做"多样性 + 可控性"，上传要做"极致低门槛 + 冷启动确定性"。

## 1. 研究背景与方法

### 1.1 研究目的
为 short-video-platform 的 MVP 立项提供用户侧证据，回答三个问题：
- **谁**是我们要服务的核心用户？
- 他们**真正要完成的任务（JTBD）**是什么？
- 在「视频上传」与「推荐流」两条主线上，**哪些需求是必备、哪些能带来惊喜**？

### 1.2 研究方法（本阶段为桌面研究 + 二手数据，后续需补充一手验证）
| 方法 | 说明 | 样本/范围 | 局限 |
|---|---|---|---|
| 桌面研究（Desk Research） | 汇总 2025-2026 年行业报告、平台公开数据 | 8+ 份权威来源 | 二手数据，颗粒度受限 |
| 竞品行为拆解 | 观察抖音/快手/视频号/TikTok/小红书的产品路径 | 5 个竞品 | 非用户直接反馈 |
| 数据建模（本次产出） | 基于行业数据构建 Persona、旅程、KANO、假设清单 | 6 个 Persona | **需一手访谈/问卷验证** |

> 说明：本报告的 Persona 为**基于行业数据的假设型 Persona（Hypothesis Persona）**，其姓名、原话为典型化合成，用于对齐团队认知，**所有定性结论均需通过第 6 节的假设清单进行一手验证**。

### 2.1 数据对产品决策的三个含义
- **含义 A：时长是零和的。** 用户总时长被抖音/快手/TikTok 高度占领，新平台必须提供"现有平台没有的确定性价值"（如更低门槛、更强可控推荐、更明确回报）。
- **含义 B：创作侧是供给瓶颈。** 日均 1.3 亿条上传意味着内容极度过剩，**"发得出去"不是问题，"被看见"才是问题**。冷启动可见度是留存关键。
- **含义 C：人群在"两头分化"。** 年轻用户追求新鲜与情绪价值，新银发（50–59 岁）是增量人群但交互容忍度低，**产品必须同时服务"高表达欲"与"低操作成本"两端**。

### Persona 1：林小满 —— 娱乐消费型 · Z 世代大学生

| 维度 | 内容 |
|---|---|
| **姓名/代号** | 林小满（代号：**Scroll-Native**） |
| **年龄段** | 19 岁（18–22 岁） |
| **职业** | 大二在读学生，偶尔做校园活动短视频 |
| **生活场景** | 课间、宿舍、通勤、睡前。手机不离手，吃饭排队都在刷视频。每天累计刷视频 2–3 小时，碎片化、无固定时段。 |
| **核心 JTBD** | “在我碎片化、无目的的闲暇里，用不费力、不踩雷的内容填满无聊时间，顺便获得谈资和情绪出口。” |
| **痛点** | ① 推荐流越刷越重复，"前 20 条还不错，后面全是同一类"；② 广告/带货混入太突兀；③ 想找某个话题的持续内容时缺乏引导；④ 对新平台有戒心——"怕注册了没人玩，刷两天就删了"。 |
| **使用行为** | 极短前 3 秒决定是否划走；高互动意愿（点赞/评论/转发梗）；几乎不发视频，但会转发到私域；对"算法推荐"有天然预期，也强烈抵触被"喂同质内容"。 |
| **对推荐流的期待** | 「开头 3 条就要命中我」；多样性优先于精确性；可一键告诉算法"不感兴趣/多推这个"；反感连续多条同类；希望看到"朋友/同校"的社交推荐。 |
| **可引用原话** | **“我刷视频就图个轻松，别让我刷十条都一个样——那不是推荐，是复读机。”** |

## 4. 用户旅程地图（User Journey Map）

覆盖阶段：**首次触达 → 注册 → 首次浏览 → 首次发布 → 首次收到反馈 → 复访/留存**。
（情绪曲线用 1–5 分表示，5 = 最积极；⭐ 表示情绪强度）

| 阶段 | 用户行为 | 触点 | 情绪曲线 | 痛点 | 机会点 |
|---|---|---|---|---|---|
| **① 首次触达** | 刷到分享链接/广告/朋友推荐，或应用商店看到；犹豫"又要下载一个新 App？" | 分享落地页、应用商店、社交私域、KOL 内容 | 3 → 2（好奇但怀疑） | 新平台"没人玩"的冷启动疑虑；下载动机不足 | 用"无需注册即可体验 30 秒推荐流"降低门槛；展示本地/同城已活跃内容作为社会证明 |
| **② 注册** | 选择手机号/微信/游客登录；填资料、选兴趣标签 | 手机号/一键登录、引导页、兴趣选择 | 3 → 3（若有摩擦则跌到 2） | 授权步数多、必填项多、担心隐私；游客模式下功能受限 | 支持游客→后置注册；兴趣标签≤5 个可选跳过；明确隐私提示；首次推荐直接开始，不逼填写 |
| **③ 首次浏览** | 滑动推荐流，前 20 秒决定去留；尝试点赞/关注/搜索 | 首页推荐流、搜索、评论、话题页 | 4 → 5（若命中）或 4 → 2（若同质/卡顿） | "前几条没兴趣就走人"；卡顿、加载慢；内容不像新人该看的 | **冷启动首刷命中率**是生死线：混合"热门 + 本地 + 社交 + 多元"，避免首刷全同类；预加载/秒开 |
| **④ 首次发布** | 想发第一条视频：拍摄或选相册、剪辑、加音乐、写文案、发布 | 拍摄页、相册导入、编辑器、发布页、权限设置 | 3 → 4（简单则喜）或 3 → 1（复杂则弃） | 剪辑门槛高、步骤多、术语难懂；银发/宝妈用户被卡在此步；上传失败/进度不明 | **一键成片 + 智能模板 + 极简发布**；上传进度可见 + 断点续传；发布前"可见范围"一键选择；新手引导只教 3 步 |
| **⑤ 首次收到反馈** | 等待播放/点赞/评论/涨粉；反复查看数据 | 通知中心、作品数据页、评论区 | 3 → 5（有反馈）或 3 → 1（0 播放） | **0 播放 / 无反馈**打击最大；不知为何被限流；无解释 | **保证新号基础曝光（冷启动流量池）**；发布后 5 分钟推送"已推送给 X 人"；零播放时给出可操作建议；鼓励互动提示 |
| **⑥ 复访/留存** | 形成使用习惯，关注账号/垂类，逐步增加发布 | 推送通知、首屏推荐、创作激励、私域分享 | 4 → 5（形成习惯） | 内容疲劳、缺乏归属感、无持续激励；工具学习成本在一次会话后遗忘 | 个性化 + 多样性推荐平衡；**创作者成长体系与激励**；定期"你的内容表现周报"；社交关系沉淀（关注/圈子） |

### 4.1 旅程关键结论
- **情绪低谷有两个**：③ 首次浏览（内容不命中）与 ⑤ 首次收到反馈（0 播放）。
- **最大机会窗口在 ④ 首次发布 → ⑤ 首次收到反馈**：这是新平台相对巨头最容易做出差异化的环节（巨头对新号冷启动普遍不友好）。
- **银发/宝妈用户会在 ④ 直接流失**：上传流程的复杂度是硬门槛，必须做到"3 步以内发布"。

## 5. 需求分层（KANO 模型）

按 KANO 三分法（基本型 Must-be / 期望型 One-dimensional / 兴奋型 Attractive），聚焦**视频上传**与**推荐流**两条主线。

### 5.1 视频上传（Video Upload）

| 需求 | KANO 类型 | 用户期望 | MVP 优先级 | 验证指标 |
|---|---|---|---|---|
| 上传成功率高、支持断点续传与大文件 | **基本型** | 默认必须做到，做不到直接流失 | P0 | 上传成功率 ≥ 99%；失败可自动重试 |
| 上传进度可见、可取消、可后台续传 | **基本型** | 不看到进度就焦虑 | P0 | 进度反馈覆盖率 100%；上传中断率 |
| 极简发布路径（≤3 步，含文案/封面/可见范围） | **基本型** | 越短越好，尤其对银发/宝妈 | P0 | 从进入发布页到发布成功的平均耗时 |
| 相册导入 + 基础剪辑（裁剪/裁剪时长） | **期望型** | 满足基本成片需求 | P0 | 使用剪辑功能的比例 |
| 智能模板 / 一键成片 / 卡点音乐推荐 | **期望型** | 降低剪门槛、提升成片质量 | P1 | 模板使用率；模板用户的发布转化率 |
| 竖屏全屏拍摄 + 美颜/滤镜 | **期望型** | 提升内容观感 | P1 | 滤镜使用率；成片完播率 |
| 发布前字幕/话题/位置等一站式配置 | **期望型** | 少跳转、少手动 | P1 | 话题/位置填写的比例 |
| **发布后即时反馈："已推送给 X 人"** | **兴奋型** | 让冷启动"看得见"，降低焦虑 | P1 | 首条视频 5 分钟内回访查看数据比例 |
| AI 生成文案/标签/字幕、智能选封面 | **兴奋型** | 帮不会写的人"变专业" | P2 | AI 功能采纳率；发布后完播率提升 |
| 多平台一键分发（跨平台） | **兴奋型** | 省时间，尤其职业/副业创作者 | P2 | 分发功能使用率 |
| 低配手机/弱网优化（压缩、降级） | 期望型 | 下沉市场刚需 | P1 | 低端机型上传成功率 |

### 5.2 推荐流（Recommendation Feed）

| 需求 | KANO 类型 | 用户期望 | MVP 优先级 | 验证指标 |
|---|---|---|---|---|
| 秒开、不卡顿、下滑流畅 | **基本型** | 体验底线 | P0 | 首帧加载时间；滑动掉帧率 |
| 首刷命中兴趣（冷启动个性化） | **基本型** | 前几条不对就卸载 | P0 | 首刷前 10 条的完播率、20 秒内跳出率 |
| 负反馈机制（不感兴趣/举报/屏蔽） | **基本型** | 控制感与安全感 | P0 | 负反馈使用率；负反馈后同质内容下降幅度 |
| 推荐多样性（避免连续同类/信息茧房） | **期望型** | 用户明确抱怨"越刷越像" | P0 | 话题多样性指数（熵）；连续同类条数 |
| 社交推荐（好友/关注/同城） | **期望型** | 增强信任与归属 | P1 | 社交来源内容的互动率 |
| 可解释推荐（"为什么推给你"） | **兴奋型** | 提升透明度与信任 | P1 | 解释入口点击率；用户信任度调研 |
| 用户可调控（兴趣标签/多样性滑杆/关自动播） | **兴奋型** | 把控制权还给用户，对抗算法疲劳 | P1 | 调控功能使用率；留存提升 |
| 支持长/深度内容的分发逻辑 | **兴奋型** | 垂类创作者刚需，巨头弱项 | P2 | 深度内容完播率、创作侧留存 |
| 实时热点 + 事件流推荐 | **期望型** | 满足谈资与时效 | P2 | 热点内容 CTR |
| LBS 同城精准推荐 | **期望型** | 本地商家核心诉求 | P1 | 同城内容到店转化率 |

### 5.3 KANO 分层洞察
- **基本型需求决定"能不能活"**：上传成功率、秒开流畅、冷启动命中、负反馈——这些是及格线，缺一即致命。
- **期望型需求决定"活得好不好"**：多样性、社交推荐、模板剪辑、兴趣调控。
- **兴奋型需求是差异化武器**：**"发布后即时可见的冷启动反馈"** 与 **"可解释 + 可调控的推荐"** 是相对抖音/TikTok 最有可能打动用户、也是成本可控的两个点，建议作为 MVP 的"惊喜点"重点投入。

## 6. 待验证假设清单（Hypothesis Backlog）

每条假设均需在 MVP 上线后或用户测试中验证，成功指标含**北极星指标（NSM）**与**护栏指标（Guardrail）**。

| # | 假设 | 验证方法 | 成功指标（北极星 / 目标） | 护栏指标（不可恶化） |
|---|---|---|---|---|
| H1 | "3 步以内完成发布"能显著提高新手首条发布率 | A/B 测试（3 步 vs 原 6 步流程） | **新用户 24h 内首条发布率** ≥ 15%（基线 5–8%） | 上传成功率不下降；举报率不上升 |
| H2 | 新号冷启动给予"保底曝光"能提升首条发布后的次日留存 | 实验组给新号固定初始曝光池 | **新创作者 7 日留存** ≥ 20% | 老用户流量占比不被过度稀释；人均时长不降 |
| H3 | 发布后"已推送给 X 人"的即时反馈能降低零反馈焦虑、提升复访 | 实验组 vs 对照组，观察查数据行为与复访 | **发布后 10 分钟内回访率** ≥ 40% | 通知打扰投诉率 |
| H4 | 推荐流"多样性（防同质）"设置能降低单次会话疲劳、提升时长 | 多样性滑杆 / 强制插入不同类目 | **人均单日使用时长** ≥ 30 分钟（首月） | 内容兴趣匹配度（CTR）不下降 |
| H5 | 用户愿意使用"可解释推荐 + 兴趣调控"功能 | 功能覆盖率 + 问卷 | **调控功能使用率** ≥ 15%；推荐信任度评分 ≥ 4/5 | 使用后推荐流 CTR 不下降 |
| H6 | 银发用户因"大字号 + 语音输入 + 极简引导"能完成上传 | 可用性测试（5–8 名 50+ 用户） | **银发用户任务完成率** ≥ 70% | 误操作率、求助率 |
| H7 | 副业/职业创作者愿为"流量确定性/数据透明"留在平台 | 种子创作者计划 + 访谈 | **种子创作者 30 日留存** ≥ 50% | 内容违规率 |
| H8 | 本地生活/LBS 推荐能带动商家到店转化 | 本地商家试点，追踪核销码 | **同城内容到店转化率** ≥ 2% | 用户对广告的负反馈率 |
| H9 | 推荐流"社交（好友/同城）"内容能提升互动与留存 | 实验组开启社交推荐 | **社交来源内容互动率** ≥ 大盘 1.5 倍 | 隐私投诉率 |
| H10 | AI 一键成片/智能文案能提高低技能用户发布意愿 | 实验组启用 AI 工具 | **AI 用户发布频次** 提升 ≥ 30% | 内容同质化/低质内容比例 |

### 6.1 北极星指标（NSM）建议
- **平台级 NSM：日均"有效创作+深度消费"用户数**（同时满足"当日观看 ≥ 10 条且完播 ≥ 3 条"或"当日发布 ≥ 1 条"的去重用户）。
- **推荐流子 NSM：日人均有效消费时长**（剔除刷屏作弊后的真实观看时长）。
- **上传子 NSM：日活跃创作者的发布成功率 × 发布频次**。

> 说明：以上阈值（如 15%、20%、30 分钟）为基于行业基线的**待验证假设值**，需在 MVP 灰度后依据实际数据校准。

## 7. 结论与产品建议

### 7.1 三条关键结论
1. **存量竞争下，胜负手在"创作侧体验"而非"消费侧时长"。** 行业数据表明用户内容极度过剩（日均 1.3 亿条上传），但新号冷启动普遍不友好。**给创作者"确定性"**（保底曝光、即时反馈、透明数据）是新平台最可行的差异化切口。
2. **上传与推荐是"信任闭环"的两端。** 一次"简单发布 → 立刻被看见 → 收到反馈"的正向体验，能同时拉动新手留存与内容供给；反之任一端断裂都会导致流失（见旅程 ④→⑤ 的情绪断崖）。
3. **人群需"两端兼顾"：高表达欲轻创作者（宝妈/副业/职业）+ 低操作成本增量人群（新银发）。** 前者决定供给与商业化，后者是行业唯一的增量人群（50–59 岁占比 20.9%），产品必须"专业功能可折叠、基础体验零门槛"。

### 7.2 对 MVP 的直接建议（供 PRD 参考）
- **P0（必备）**：上传成功率与进度反馈、≤3 步极简发布、首刷冷启动个性化、秒开流畅、负反馈与举报。
- **P1（差异化）**：新号保底曝光池、发布后即时反馈、推荐多样性与可解释/可调控、智能模板一键成片、LBS 同城推荐。
- **P2（后续）**：AI 全链路创作助手、跨平台分发、长/深度内容分发逻辑、创作者成长与分成体系。

### 7.3 下一步行动
1. 对 6 个 Persona 各招募 3–5 名真实用户进行**深度访谈 + 可用性测试**，验证 H1/H2/H6。
2. 搭建 MVP 灰度环境，针对 H1、H3、H4 设计 A/B 实验。
3. 与 docs/01-competitor-analysis.md 对齐，确认差异化功能的可行性。
