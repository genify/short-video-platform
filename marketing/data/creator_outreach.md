# 渠道 1/2 衔接｜种子创作者 1v1 招募话术（T0 前使用版本）

> 适用：Marketing & Growth 用人工方式联系种子创作者（假门留资后的一对一邀请）。
> 纪律：T0 前**只允许不含量化承诺的招募信息**；承诺卡见 `marketing/data/creator_promise_card.md`（T0 起才可发）。
> 合规：本文件由合规器按 pre_t0 相位扫描。

## 1. 三步触达（每步只做一件事）

### 第 1 步：破冰（不做承诺，只问意愿）

```
你好，看到你在拍{垂类}内容。我们在做一个垂类短视频社区的内测，
现在只招第一批创作者，邀请制。
想先问你一句：你更在意「流量规则说清楚」，还是「发出去有人看」？
只要回我一个词就行，我不发广告。
```

**为什么这样问**：直接对应本单第一批要测的三个价值主张（V1 被看见 / V2 规则透明 / V3 省时间）。创作者的自然回答就是最便宜的分流线索，可与其后续落地页行为交叉验证。

### 第 2 步：给材料（把选择权交给对方）

```
材料在这里，不用注册就能看，看完再决定：
{专属招募链接}
我们是把「首发内容能不能被看见」做成产品里的一条规则，而不是一句运营口号；
具体数值规则会在功能开放时一起公开（现在还不方便给数字，给了就是空头承诺）。
```

### 第 3 步：确认（写明边界，留痕）

```
如果你愿意，我先把你加进第一批名单。三件事先说清楚：
① 我们只收你这一个联系方式，只用来发内测邀请；
② 数据保留 90 天，到期删除，你可以随时说「退出」；
③ 现在还不能承诺任何数字，等规则开放我会把规则原文发你，你再决定要不要首发。
```

## 2. 必须写明的三件事（伦理红线，缺一不可）

| # | 事项 | 依据 |
|---|---|---|
| 1 | 收集目的（只用于内测邀请） | PRO-4 §4.3 伦理红线 |
| 2 | 保留期（90 天，到期删除） | 同上 |
| 3 | 退出方式（回复「退出」即删除） | 同上 |

## 3. 禁止说的话（T0 前）

- 任何数字承诺（如曝光量、涨粉、收入、分成比例）一律不得出现：见 `lexicon.json` HB-05、HB-11、HB-12、TG-01～TG-06。
- 任何效果承诺，即使没有数字（如「保证有人看」类表述），一律禁止：见 TG-05、TG-06。
- 任何未上线能力：见 HB-13。
- 任何竞品贬损或未公开来源的对比数字：见 HB-02、HB-03、HB-04、HB-10、HB-14。
- 任何现金/补贴暗示：见 HB-15（本单不做现金获取创作者）。

## 4. 常见反问与标准答法

| 创作者问 | 标准答法（T0 前） | 不得答 |
|---|---|---|
| 「首发能给多少曝光？」 | 「规则还没开放，现在给你数字就是空头承诺。规则开放时我会把原文发你，你可以先看规则再决定。」 | 不得给任何数字 |
| 「你们和抖音有什么区别？」 | 「我们不比算法精度。差别在：我们把首发的曝光规则写成产品里的一条硬约束（具体数值规则开放时一并公开），而且你会看到每条内容的推荐理由。」 | 不得引用对手未公开来源的数字 |
| 「有补贴吗？」 | 「没有现金补贴，也没有买量。我们给的是规则和可核对的数据。」 | 不得暗示补贴 |
| 「要独家吗？」 | 「不要求独家，只测首发。」 | 不得暗示独家绑定 |
| 「什么时候能用？」 | 「功能开放时间由工程侧交付决定，我不给你日期承诺；名单里的人会第一时间收到通知。」 | 不得给日期承诺 |

## 5. 记录要求（供 A7 与循环 θ 归因）

> 本表为**内部记录口径，不得对外引用**（含「7 天内首发率 ≥ 50%」等阶段判据；对外只表述机制与邀请制）。

| 字段 | 说明 |
|---|---|
| creator_code | 与 `marketing/data/seed_creators.csv` 一致 |
| 触达时间 / 渠道 | 人工记录（无产品内埋点） |
| 第 1 步回答 | 被看见 / 规则透明 / 省时间（三选一） |
| 留资与否 | 是否提交 `form_submit` |
| 邀请发出时间 | 用于「7 天内首发率 ≥ 50%」的阶段判据（内部判据，不得对外引用） |
| 是否为内部/邻近人群 | 内部人群必须与正式队列分开统计，不得混入 A7 分子 |

> 归因纪律：θ（循环贡献占比）的唯一口径是邀请码/来源参数；人工触达记录不参与 θ，只用于 A7。
> **名额发放顺序口径**：邀请名额按留资顺序发放，顺序以落地页 `form_submit` 入库时间为准。对外只表述为「邀请名额 / 专属链接」，不使用装置里不存在的「邀请码」。
