# 确定性承诺卡（T0 起才可对外发出）

> **硬门**：本卡片的任何内容在 T0（MVP 可灰度日，由 PRO-7 交付触发）之前**不得对外发布**。
> **兑现纪律**：卡片一旦发出，必须在 **7 天内以真实数据兑现**；无法兑现即视为欺骗性设计，**立即停止投放**（PRO-4 §4.3 伦理红线 → PRO-8 §0.3）。
> 合规：本文件按 t0 相位扫描（只禁 hard_ban）；含 §3.5 白名单的 3 个数字。

## 1. 对外承诺（只允许这 3 个数字 + 2 条非数字承诺）

| # | 承诺 | 口径定义（必须一并给出） |
|---|---|---|
| 1 | 首发 24h 曝光 **P10 ≥ 50 次** | 同批创作者首发视频在发布后 24 小时内的曝光量分布，其**第 10 百分位不低于 50 次**。P10 指把同批创作者的曝光量从小到大排序后第 10% 位置的值，不是平均值。 |
| 2 | 同批创作者曝光 **Gini ≤ 0.6** | 同批创作者 24h 曝光量的基尼系数不高于 0.6（0 = 完全平均，1 = 全部集中在一个人身上）。 |
| 3 | 单条 feed 内同一创作者 **≤ 2 条**、7 天内不重复推荐同一条 | 一条推荐流里，同一个创作者最多出现 2 条；同一条内容 7 天内不会重复推给同一个人。 |
| 4 | 推荐理由可见（非数字） | 每条推荐都附一行可读理由，创作者可在自己的作品页回读。 |
| 5 | 分成规则**先公开后结算**（非数字） | MVP 阶段**不结算**；规则文本先公开，再谈结算。不做任何收入承诺。 |

**不得出现在本卡片、也不得出现在任何投放物料里的表述**：见 `lexicon.json` 的 HB-01～HB-15（按编号引用，此处不复述）。

## 2. 兑现界面（工程依赖）

| 依赖 | 内容 | 归属 |
|---|---|---|
| `exposure` 埋点 | 曝光/展现计数（当前未实现，为最高优先阻塞项） | PRO-7 |
| `GET /api/videos/{id}/exposure` | 返回真实 `exposures`、`impressions`、`views`、`creator_exposure_p10`；**禁止写死或夸大** | PRO-7（PRD v2.0 已列 P0） |
| 上传成功响应 | **不含**曝光数字（避免与「已推送给 X 人」的实时性混淆） | PRO-7 |
| 兑现位解读 | 必须写明「这是真实曝光数，不是预估，也不是播放量」 | 本团队（文案） |

**未兑现时的处置（预置）**：① 立即暂停全部投放；② 24 小时内向已发卡片的创作者逐条说明；③ 由本 Agent 提交复盘，写入 PRO-8 §6.2 失败信号台账。

## 3. 发卡流程（每名创作者）

1. 确认 T0 已到（PRO-7 交付 + §0.3 八项前置全绿）。
2. 用该创作者的专属链接替换 `{专属招募链接}`，卡片与其链接一一对应。
3. 发出前跑一次 `python3 marketing/scripts/compliance_lint.py`，确认本文件无违规。
4. 发出后 7 天内回收真实数据；把回收结果按 `creator_code` 记入台账，用于 A7 与 θ 的归因。
