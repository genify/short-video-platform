# 渠道 2｜统一分享话术模板（T0 前使用版本）

> 适用：种子创作者把「专属链接 + 二维码」发到自己的站外渠道（微信、抖音私信、小红书、社群）。
> 纪律：**本文件所有版本都不得出现任何未兑现数字**。承诺类、数字类表述一律留到 T0 之后的《确定性承诺卡》。
> 合规：本文件由 `marketing/scripts/compliance_lint.py` 按 `lexicon.json` 的 hard_ban + t0_gated 逐条扫描（禁用项以规则编号引用，不在此复述）。

## 0. 使用前三条硬门

1. **拿到自己的专属链接**：链接必须来自 `marketing/out/links/<creator_code>_<platform>.txt`，不得手改参数（改了就无法归因到该创作者）。
2. **话术不得改写**：可删减，不得新增任何数字或承诺（含「保证」「一定」「包」类词）。
3. **一次只发一跳**：私信/群公告发一次即可，不重复轰炸；同一社群 7 天内不超过 2 条。

## 1. 主话术（微信 1v1 / 老客户）

```
我在试一个刚开放内测的垂类短视频社区，走邀请制。
他们做的是「把首发内容能不能被看见，写成一条产品里的规则」，而不是发一句运营口号。
我的第一条已经发上去了，你可以直接点开看，不用注册：
{专属链接}
（用的是我的邀请名额，名额有限）
```

## 2. 社群版（垂类兴趣群，公开发言）

```
跟大家报一个我在用的内测产品：垂类短视频（美食/探店/本地生活方向）。
规则在开放前公开，每条内容都带一行可读的推荐理由——这点比我用过的平台都清楚。
我的主页在这里，点开直接能看，不用注册也不用下载：
{专属链接}
```

## 3. 短视频平台私信版（抖音 / 小红书观众）

```
谢谢关注。我在一个内测的垂类社区同步更新，那边会显示每条的推荐理由，
不用注册就能看：{专属链接}
如果点不开，回我一句，我直接发你视频。
```

## 4. 二维码使用场景

| 场景 | 用哪个文件 | 话术 |
|---|---|---|
| 视频片尾 / 直播贴片 | `marketing/out/qr/<link_id>.png` | 「扫码看完整版」 |
| 门店/市集线下物料 | `marketing/out/qr/<link_id>.svg` | 「扫码直接播，不用下载」 |
| 微信群公告 | 两者皆可 | 用第 2 节话术 |

## 5. 禁用清单（按规则编号引用，不得在话术里出现）

- 一切数字承诺与效果承诺：见 `marketing/compliance/lexicon.json` 的 HB-11、HB-12、TG-01～TG-06。
- 一切竞品对照与攻击性表述：见 HB-14、HB-02、HB-03、HB-10。
- 一切未上线能力：见 HB-13。
- 一切「社交关系链」类表述：见 HB-08。

## 6. 回执口径（渠道 2 的取数）

| 指标 | 口径 | 判据 |
|---|---|---|
| 观看向分享率 | 发生分享的观看数 ÷ 观看数 | ≥ 3%（自设） |
| 分享 → 落地页消费 | 带分享参数的落地页消费 UV ÷ share 事件数 | ≥ 25% |
| 落地页消费 → 注册 | 带站外来源参数的新注册数 ÷ 落地页消费 UV | ≥ 8% |

> 三条都依赖 §0.3 #5（来源参数 + 归因落库）与分享落地页（本单交付 `marketing/landing/`）；T0 前显示为「不可计算」，不得用近似值占位。
