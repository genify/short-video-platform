# 渠道 2｜统一分享话术模板（T0 前使用版本）

> 适用：种子创作者把「专属链接 + 二维码」发到自己的站外渠道（微信、抖音私信、小红书、社群）。
> 纪律：本文件在 `pre_t0` 相位下**不得出现任何数字与任何结果承诺**（含无数字表述，如「有人看」「被看见」）；词例仅作提示，不作为判断边界。承诺类、数字类表述一律留到 T0 之后的《确定性承诺卡》。
> 纪律（第二轮）：**一切竞品对照与比较性贬损同样禁止**——只能做自我陈述，不得以「比别的平台如何」的方式表达。
> 合规：本文件由 `marketing/scripts/compliance_lint.py` 按 `lexicon.json` 的 hard_ban + t0_gated 逐条扫描（禁用项以规则编号引用，不在此复述）。

## 0. 使用前三条硬门

1. **拿到自己的专属链接**：链接必须来自 `marketing/out/links/<creator_code>_<platform>.txt`，不得手改参数（改了就无法归因到该创作者）。
2. **话术不得改写**：可删减，不得新增任何数字或承诺。
   - **以下句子不可删**（其余宣传句可自由删减）：
     - 「不用注册就能看 / 不用注册也不用下载」——「不强制注册」的口径锚点（RT-04）；
     - 「邀请名额 / 邀请制」——邀请制的口径锚点；
     - 社群版的身份披露句——「我是创作者，不是官方号」。
   - 正文中以 `〈不可删〉` 标记的句子属上述三类，删掉即视为话术失效，不得发布。
3. **一次只发一跳**：私信/群公告发一次即可，不重复轰炸；同一社群 7 天内不超过 2 条。

## 1. 主话术（微信 1v1 / 老客户）

```
我在试一个刚开放内测的垂类短视频社区，走邀请制。〈不可删〉
他们做的是「把首发的曝光规则写成产品里的一条硬约束」，而不是发一句运营口号。
我的第一条已经发上去了，你可以直接点开看，不用注册：〈不可删〉
{专属链接}
（用的是我的邀请名额，名额有限）〈不可删〉
```

## 2. 社群版（垂类兴趣群，公开发言）

```
我是创作者，不是官方号。〈不可删〉
跟大家报一个我在用的内测产品：垂类短视频（美食/探店/本地生活方向）。
规则在开放前公开，每条内容都带一行可读的推荐理由——理由的展示位随功能开放，开放后这一点我能自己核对。
我的主页在这里，点开直接能看，不用注册也不用下载：〈不可删〉
{专属链接}
```

> 改动说明：本版原句含竞品对照（已按 HB-16 处置），改为自我陈述——主语回到自己，不涉对手。本文件不保留任何对照式表述。

## 3. 短视频平台私信版（抖音 / 小红书观众）

```
谢谢关注。我在一个内测的垂类社区同步更新，那边会显示每条的推荐理由（展示位随功能开放），
不用注册就能看〈不可删〉：{专属链接}
如果点不开，回我一句，我把视频发在这里的评论区。
```

> 改动说明：末句原为「我直接发你视频」（一对一的私下履约承诺、无留痕），已改为公开可核查的动作（发在评论区）。

## 4. 二维码使用场景

## 5. 禁用清单（按规则编号引用，不得在话术里出现）

- 一切数字承诺与效果承诺：见 `marketing/compliance/lexicon.json` 的 HB-11、HB-12、TG-01～TG-06。
- 一切竞品对照与攻击性表述（对照式比较句）：见 HB-14、**HB-16**、HB-09。
- 一切未上线能力（非变现类与变现类一并）：见 HB-13、**HB-17**。
- 「保底 / 下限」类定量表述（与已删除的旧口径同义）：见 HB-01、**HB-18**。
- 一切「社交关系链」类表述：见 HB-08。

## 6. 回执口径（渠道 2 的取数）

> **内部口径，不得对外引用**（下表为内部 KPI，不是可对外表述的承诺）。

| 指标 | 口径 | 判据 |
|---|---|---|
| 观看向分享率 | 发生分享的观看数 ÷ 观看数 | ≥ 3%（自设） |
| 分享 → 落地页消费 | 带分享参数的落地页消费 UV ÷ share 事件数 | ≥ 25% |
| 落地页消费 → 注册 | 带站外来源参数的新注册数 ÷ 落地页消费 UV | ≥ 8% |

> 三条都依赖 §0.3 #5（来源参数 + 归因落库）与分享落地页（本单交付 `marketing/landing/`）；T0 前显示为「不可计算」，不得用近似值占位。
